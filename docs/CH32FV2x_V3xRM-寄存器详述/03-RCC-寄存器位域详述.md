# RCC / OSC 寄存器位域详述

**来源**：《CH32FV2x_V3xRM》**第 3 章**（表 3-1、3-2 及 3.4 节）。  
**基址**：`R32_RCC_*` 自 **`0x40021000`** 起。  
**原文 PDF**：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)  
**ch32fun**：`RCC` → `RCC_TypeDef`（如 `CTLR` ↔ `R32_RCC_CTLR`）。

> **型号差异**：`PLL2`/`PLL3`、部分 **CFGR0** 位、**CFGR2** 整体等多仅 **D8C** 等才有；**V20x_D6** 的 **CSSON** 有批号限制。以下凡写“见手册”处请以 PDF 中 **注** 为准。

## 2. `RCC_CTLR`（偏移 0x00，时钟控制）

| 位 | 名 | 访问 | 描述 | 复位 |
|----|-----|------|------|------|
| `[31:30]` | — | RO | 保留 0 | 0 |
| 29 | **PLL3RDY** | RO | PLL3 锁相就绪（D8C 等） | 0 |
| 28 | **PLL3ON** | RW | 1=开 PLL3；进停机/待机硬件可清 0 | 0 |
| 27 | **PLL2RDY** | RO | PLL2 就绪 | 0 |
| 26 | **PLL2ON** | RW | 1=开 PLL2 | 0 |
| 25 | **PLLRDY** | RO | 主 PLL 就绪 | 0 |
| 24 | **PLLON** | RW | 1=开主 PLL | 0 |
| `[23:20]` | — | RO | 保留 0 | 0 |
| 19 | **CSSON** | RW | **时钟安全监测** 1=当 HSE 就绪时监测 HSE；HSE 故障可产生 **NMI** 等 | 0 |
| 18 | **HSEBYP** | RW | 1=HSE **旁路**外时钟；须 **HSEON=0** 时写 | 0 |
| 17 | **HSERDY** | RO | HSE 稳定 1=就绪 | 0 |
| 16 | **HSEON** | RW | 1=开 HSE；低功耗可硬件清 0 | 0 |
| `[15:8]` | **HSICAL[7:0]** | RO | HSI 校准值，上电加载 | `xx` |
| `[7:3]` | **HSITRIM[4:0]** | RW | 在 HSICAL 上**微调** HSI；**默认 10000b(16)**，约 ±0.25% @8MHz，步进约 20kHz | `10000b` |
| 2 | — | RO | 保留 0 | 0 |
| 1 | **HSIRDY** | RO | HSI 稳定 | 1 |
| 0 | **HSION** | RW | 1=开 HSI；待机返回/HSE 故障时硬件可**强制置 1** | 1 |

**注**：`CSSON` 对 **V20x_D6 且批号倒数第 5 位=0** 见手册注（功能不适用）。

## 3. `RCC_CFGR0`（偏移 0x04，时钟配置 0）

| 位域 | 名 | 访问 | 说明 |
|------|-----|------|------|
| 31 | **ADCDUTY** | RW | ADC 时钟占空比调整：`0`=50%；`1`=低电平更长 |
| 30 | **ADC_DUTY_SEL** | RW | ADC 时钟占空比选择：`0`=50%；`1`=75%（**独立位**，与 31 位无配合关系）；仅 **CH32F20x_D8/D8C、CH32V30x_D8/D8C、CH32V31x_D8C 批号倒数第六位不为 0** 的产品 |
| 29 | — | RO | 0 |
| 28 | **ETHPRE** | RW | 以太网前级 0=不分频，1=2 分频（V20x_D8W 等） |
| `[27:24]` | **MCO[3:0]** | RW | MCO 引脚输出源：0000=无时钟；`0100` SYSCLK；`0101` HSI；`0110` HSE；`0111` PLL/2；`1000` PLL2；`1001` PLL3/2；`1010` XT1；`1011` PLL3 等，见手册**完整表**与切换毛刺注 |
| `[23:22]` | **USBPRE[1:0]** | RW | USB **48MHz** 产生：`00` 1 分频（PLL=48M）；`01` 2 分频(96M)；`10` 3 分频(144M)；`11` 5 分频 + HSE/2/PLL=240M（**子集型号**） |
| `[21:18]` | **PLLMUL[3:0]** | RW | **与型号强相关**，见**下一节** |
| 17 | **PLLXTPRE** | RW | HSE 进 PLL 的**预分频** + 与 `CFGR2[0]` **联动**（见手册 3.4.2 长文） |
| 16 | **PLLSRC** | RW | PLL 入源为 HSI/HSE/或 D8C 的 PREDIV1 等，分型号表 |
| `[15:14]` | **ADCPRE[1:0]** | RW | ADC 时钟 = PCLK2 除 2/4/6/8；**ADC 时钟不得超 ~14MHz**（手册 3.4.2 注） |
| `[13:11]` | **PPRE2[2:0]** | RW | PCLK2 = HCLK 或 /2/4/8/16（`0xx`=1:1 等，见 3.4.2 表） |
| `[10:8]` | **PPRE1[2:0]** | RW | PCLK1 分频，同上 |
| `[7:4]` | **HPRE[3:0]** | RW | HCLK=SYSCLK 或 /2/4/8/16/64/128/256/512，见 3.4.2 表 |
| `[3:2]` | **SWS[1:0]** | RO | **只读**当前系统选择：`00` HSI，`01` HSE，`10` PLL |
| `[1:0]` | **SW[1:0]** | RW | **写**选 SYSCLK 源，须待目标**就绪**；`CSS` 时硬件可**强切 HSI**（见 3.4.2 注） |

### 3.1 `PLLMUL[3:0]` 编码（必须对照您的 **密度/子系列**）

- **CH32F20x_D6/D8/D8W、CH32V20x_D6/D8/D8W、CH32V30x_D8**：**`0000`=×2、`0001`=×3 … `1110`=×16、`1111`=×18**。
- **CH32F20x_D8C、CH32V30x_D8C、CH32V31x_D8C**：**`0000`=×18、`0001`=×3、`0010`=×4、`0011`=×5、`0100`=×6、`0101`=×7、`0110`=×8、`0111`=×9、`1000`=×10、`1001`=×11、`1010`=×12、`1011`=×13、`1100`=×14、`1101`=×6.5、`1110`=×15、`1111`=×16**（**无 ×20**；×20 仅见于 **`CFGR2` 的 `PLL2MUL` / `PLL3MUL`**）。

**编程顺序**：先配 **PLLSRC / PLLXTPRE / PLLMUL** 与 `CFGR2` 的 **PREDIV* / PLL2MUL / PLL3MUL**，再 **置 PLLON**，轮询 **PLLRDY**，最后 **SW=10** 切到 PLL。

## 4. `RCC_INTR`（+0x08，时钟中断）

**高半字**（`[31:16]`）多为 **清标志** 写 1 清除（`CSSC、PLL3RDYC…、LSIRDYC`）；**低半字/中间** 为**使能** 与**状态标志**成对出现（`PLL3RDYIE/PLL3RDYF` 等）。

- **7 `CSSF`**：RO，HSE 故障触发时钟安全，配合 **NMI** 等。
- **状态位** `*RDYF` 置位后，向对应对齐 **`xxxRDYC` 写 1** 清。

`PLL2`/`3` 相关位仅 **D8C 系** 存在。

---

## 5. `RCC_APB2PRSTR`（+0x0C，APB2 外设**复位**）

典型位（0=无效，1=**复位**该外设）：

`AFIORST(0) IOPARST(2) IOPBRST(3) IOPCRST(4) IOPDRST(5) IOPERST(6) [8:7]R ADC1RST(9) ADC2RST(10) TIM1RST(11) SPI1RST(12) TIM8RST(13) USART1RST(14) TIM9RST(19) TIM10RST(20) …`  
（`TIM9/10` 位号以手册 3.4.4 图与您的封装为准。）

---

## 6. `RCC_APB1PRSTR`（+0x10，APB1 复位）

含 **`TIM2RST`～`TIM7`、WWDG、`USART2`～`8`、`SPI2/3`、`USBD、CAN1/2、BKR、PWR、DAC` 等**，各位含义均为：**1= 复位该模块**。

---

## 7. `RCC_AHBPCENR`（+0x14，AHB 外设**时钟使能**）

功能位为 **0=关时钟，1=开**（与手册 3.4.6 一致，常见）：

- **DMA1EN(0)、DMA2EN(1)、SRAMEN(2)** 等
- **CRC、FSMC、RNG、SDIO、USBHS、OTGFS、DVP、ETHMAC、ETH 收发** 等，**V20x_D8W 另含 BLES/BLEC**（BLE 相关，见表）
- 具体位号以 PDF 图 3.4.6 为准，因不同引脚/封装图可能**列在相邻位**

---

## 8. `RCC_APB2PCENR` / `RCC_APB1PCENR`（+0x18、+0x1C）

与**复位寄存器**各位**名称对应**，改为 **EN**：使能**访问时钟**。操作外设前**必须先** `*EN=1`（除非另有门控，如 BKP+PWR）。

---

## 9. `RCC_BDCTLR`（+0x20，后备域）

| 位域 | 名 | 说明 |
|------|-----|------|
| 16 | **BDRST** | 1=整**后备域**软件复位（含 BKP/RTC 部分，见手册） |
| 15 | **RTCEN** | **RTC 时钟**；**仅** `RTCSEL≠0` 时才能真正使能（否则硬件强制 0） |
| `[9:8]` | **RTCSEL[1:0]** | `00` 无时钟；`01` LSE；`10` LSI；`11` HSE/分频（**分频因型号不同**，长注见） |
| 2 | **LSEBYP** | LSE 旁路，须 **LSEON=0** 时配 |
| 1 | **LSERDY** | LSE 就绪（RO） |
| 0 | **LSEON** | 开 LSE |

**写保护**：改 **LSEON/RTCSEL/…** 前需 **`PWR_CTLR.DBP=1`**（开后备域写权限）。

---

## 10. `RCC_RSTSCKR`（+0x24，复位标志与 LSI）

| 位 | 名 | 说明（RO 标志，**写 RMVF 或依手册清**） |
|----|-----|----------------------------------------|
| 31 | **LPWRRSTF** | 低功耗复位 |
| 30 | **WWDGRSTF** | 窗口看门狗复位 |
| 29 | **IWDGRSTF** | 独立看门狗复位 |
| 28 | **SFTRSTF** | 软件复位 |
| 27 | **PORRSTF** | 上电/掉电复位，上电后常为 1 |
| 26 | **PINRSTF** | NRST 引脚 |
| 24 | **RMVF** | 写 1 清**上述标志** |
| 1 | **LSIRDY** | LSI ~40k 就绪 |
| 0 | **LSION** | 开 LSI，供 IWDG/部分 RTC 等 |

---

## 11. `RCC_AHBRSTR`（+0x28，AHB 复位）

含 **`ETHMACRST`、`DVPRST`、`OTGFSRST` 等** 仅部分型号有；其余 **Reserved=0**。

---

## 12. `RCC_CFGR2`（+0x2C，时钟配置 2，**D8C 等**为主）

- **`USBFSSRC(31)`**：0=从 PLL 取 48M；1=**USB PHY** 路径  
- **`USBHSPLL(30)` 、`USBHSCLK[1:0](29-28)`（`00`=3 MHz / `01`=4 MHz / `10`=8 MHz / `11`=5 MHz）、`USBHSPLLSRC(27)`（0=HSE / 1=HSI）、`USBHSDIV[2:0](26-24)`（`000`=÷1 … `111`=÷8）**：USB 高速与 PHY 参考频率  
- **`ETH1GEN(22)`**：千兆以太网 125MHz 时钟使能；**`ETH1GSRC[1:0](21-20)`**：`00`=PLL2 VCO、`01`=PLL3 VCO、`1x`=外部 PB1 引脚输入  
- **`RNGSRC(19)`（0=SYSCLK / 1=PLL3 VCO）、`I2S3SRC(18)`、`I2S2SRC(17)`、`PREDIV1SRC(16)`（0=HSE / 1=PLL2）**  
- **`PLL3MUL[3:0](15-12)`、`PLL2MUL[3:0](11-8)`**：`0000`=×2.5、`0001`=×12.5、`0010..1110`=×4..×16、**`1111`=×20**（即 `PLL2MUL` / `PLL3MUL` 可到 ×20，`CFGR0.PLLMUL` 不可）  
- **`PREDIV2[3:0](7-4)`、`PREDIV1[3:0](3-0)`**：`0000`=不分频、`0001..1111`=÷2..÷16  
- **`PREDIV1[0]` 与 `CFGR0.PLLXTPRE(17)` 为同一位**，改一处会同步另一处（手册 3.4.12 末注）  
- **注**：`CFGR2` **适用对象** 以 "CH32F20x_D8C、CH32V30x_D8C、CH32V31x_D8C" 为主（见 3.4.12 末）
