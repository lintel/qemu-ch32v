# RNG（随机数发生器）寄存器位域详述

**来源**：《CH32F/V20x_V30x_V31x 系列应用手册》V2.4（[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)），**第 29 章「随机数发生器（RNG）」**（PDF **p514–516**）。  
**适用**：**CH32F20x / CH32V30x / CH32V31x 系列部分产品**（含模拟 RNG；CH32V20x 无此模块）。

---

## 1. 原理

基于**连续模拟噪声种子**的 **LFSR**（线性反馈移位寄存器），主机读取 `RNG_DR` 时提供 32 位随机数。LFSR 由 **PLL48CLK** 驱动（与 USB 共用 48 MHz 时钟），所以随机数质量受 **HCLK** 影响。

**需要的时钟**：
- `RCC_AHBPCENR.RNGEN(bit9)=1` 使能 RNG 时钟；
- **PLL48CLK 必须就绪**（配置 `CFGR0.USBPRE` 或 `CFGR2.USBFSSRC` 以拿到 48 MHz；否则 `SR.CECS=1`）。

---

## 2. 表 29-1 寄存器（基址 `0x40023C00`）

| 名称 | 地址 | 偏移 | 描述 | 复位 |
|------|------|------|------|------|
| `R32_RNG_CR` | `0x40023C00` | `0x00` | 控制 | `0x00000000` |
| `R32_RNG_SR` | `0x40023C04` | `0x04` | 状态 | `0x00000000` |
| `R32_RNG_DR` | `0x40023C08` | `0x08` | 数据 | `0x00000000` |

---

## 3. 位域

### 3.1 `R32_RNG_CR`（`0x00`）— 控制

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[31:4]` | Reserved | RO | — | 0 |
| 3 | **`IE`** | RW | 随机数就绪 / 出错时产生中断 | 0 |
| 2 | **`RNGEN`** | RW | 使能 RNG（激活模拟电路 + LFSR + 错误检测器） | 0 |
| `[1:0]` | Reserved | RW | — | 0 |

### 3.2 `R32_RNG_SR`（`0x04`）— 状态

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| `[31:7]` | Reserved | RO | — |
| 6 | **`SEIS`** | RW | 种子错误中断状态（与 `SECS` 同步）：检测到 **> 64 位连续相同** 或 **> 32 位连续交替 0/1** |
| 5 | **`CEIS`** | RW | 时钟错误中断状态（与 `CECS` 同步） |
| `[4:3]` | Reserved | RO | — |
| 2 | **`SECS`** | RO | 种子错误当前状态 |
| 1 | **`CECS`** | RO | 时钟错误当前状态（未检测到 PLL48CLK） |
| 0 | **`DRDY`** | RO | `1`=`DR` 有效可读；读 `DR` 后自动清 0 |

> **错误恢复**：
> - 时钟错误（`CECS/CEIS=1`）→ 修正时钟配置后 **写 1 清 `CEIS`**；已出过的随机数仍有效；
> - 种子错误（`SECS/SEIS=1`）→ 当前 `DR` 不可用：先清 `SEIS`，然后 `RNGEN=0→1` **重启** RNG。

### 3.3 `R32_RNG_DR`（`0x08`）— 数据

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| `[31:0]` | **`RNDATA`** | RO | 32 位随机数（需 `DRDY=1` 才有效） |

---

## 4. 典型用法

```c
RCC->AHBPCENR |= RCC_RNGEN;         // 使能 RNG 时钟
// 确保 PLL48 时钟就绪（USBPRE 已配置），否则 CECS=1
RNG->CR = (1<<2);                   // RNGEN=1
while ((RNG->SR & 1) == 0);         // 等 DRDY=1
uint32_t r = RNG->DR;               // 32 位随机数
```
