# IWDG（独立看门狗）/ WWDG（窗口看门狗）寄存器位域详述

**来源**：《CH32F/V20x_V30x_V31x 系列应用手册》V2.4（[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)），**第 7/8 章**（PDF **p67–73**）。  
**适用**：CH32F20x / V20x / V30x / V31x **全系列**。

---

## 1. IWDG — 独立看门狗（第 7 章）

### 1.1 特征

- **12 位自减计数器**，时钟 = **LSI（~40 kHz）经 `PSCR` 分频**；
- **独立运行**：在 **停机/待机** 下继续计时（可用于把 MCU 从低功耗唤醒复位）；
- **超时 = （`RLDR` + 1）× LSI 分频周期**；
- **键值锁**：写 `CTLR` 三种魔数（`0x5555 / 0xAAAA / 0xCCCC`）；
- 若选项字 `USER.IWDG_SW` 使能**硬件独立看门狗**，复位后**自动启动**，无需软件写 `0xCCCC`。

### 1.2 表 7-1 寄存器（基址 `0x40003000`）

| 名称 | 地址 | 偏移 | 描述 | 复位 |
|------|------|------|------|------|
| `R16_IWDG_CTLR` | `0x40003000` | `0x00` | 键值控制 | `0x0000` |
| `R16_IWDG_PSCR` | `0x40003004` | `0x04` | 分频 | `0x0000` |
| `R16_IWDG_RLDR` | `0x40003008` | `0x08` | 重装载值 | `0x0FFF` |
| `R16_IWDG_STATR` | `0x4000300C` | `0x0C` | 状态 | `0x0000` |

### 1.3 `R16_IWDG_CTLR`（`0x00`）— 键值

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| `[15:0]` | **`KEY[15:0]`** | WO | `0xAAAA`=**喂狗**（把 `RLDR` 装入计数器）；`0x5555`=**解锁 `PSCR/RLDR` 写保护**；`0xCCCC`=**启动 IWDG** |

### 1.4 `R16_IWDG_PSCR`（`0x04`）— 分频

| 位 | 名称 | 描述 | 复位 |
|----|------|------|------|
| `[15:3]` | Reserved | — | 0 |
| `[2:0]` | **`PR[2:0]`** | `000`=÷4、`001`=÷8、`010`=÷16、`011`=÷32、`100`=÷64、`101`=÷128、`110/111`=÷256 | `000b` |

> 改此域前须 `KEY=0x5555`；读前须 `STATR.PVU=0`。

### 1.5 `R16_IWDG_RLDR`（`0x08`）— 重装载

| 位 | 名称 | 描述 |
|----|------|------|
| `[15:12]` | Reserved | — |
| `[11:0]` | **`RL[11:0]`** | 12 位重装载值（写入需 `KEY=0x5555`；喂狗 `KEY=0xAAAA` 时硬件装入） |

### 1.6 `R16_IWDG_STATR`（`0x0C`）— 状态

| 位 | 名称 | 描述 |
|----|------|------|
| `[15:2]` | Reserved | — |
| 1 | **`RVU`** | `RLDR` 更新中；**为 1 时读写 `RLDR` 无效**（最多 5 个 LSI 周期） |
| 0 | **`PVU`** | `PSCR` 更新中；同上约束 |

> 注：写完 `PSCR/RLDR` 后**不必等** `PVU/RVU` 变 0，可继续执行（即使在低功耗下）。

### 1.7 典型用法

```c
IWDG->CTLR = 0x5555;            // 解锁
IWDG->PSCR = 4;                 // ÷64 → ~625 Hz
IWDG->RLDR = 0x0FFF;            // 超时 ≈ 4096 / 625 ≈ 6.55 s
IWDG->CTLR = 0xCCCC;            // 启动
// ... 主循环内周期喂狗：
IWDG->CTLR = 0xAAAA;
```

## 2. WWDG — 窗口看门狗（第 8 章）

### 2.1 特征

- **7 位自减计数器**，时钟 `WWDG_CLK = PCLK1 / 4096 / (1 << WDGTB)`；
- **双条件复位**：① `T[6]` 由 1→0（即 `T[6:0]` 从 `0x40` 减到 `0x3F`）；② 在**不允许**的时间窗口（`T > W`）内写 `T[6:0]`；
- **提前唤醒中断 EWI**：`T` 到达 `0x40` 时 `EWIF=1`（可产生中断，只有 1 个计数器周期可喂狗）；
- 启动后**不能关闭**，除非**系统复位**；可通过关 `WWDGEN` 时钟**暂停**计数（等效间接停用）。

### 2.2 表 8-1 寄存器（基址 `0x40002C00`）

| 名称 | 地址 | 偏移 | 描述 | 复位 |
|------|------|------|------|------|
| `R16_WWDG_CTLR` | `0x40002C00` | `0x00` | 控制（`WDGA`、计数值 `T[6:0]`） | `0x007F` |
| `R16_WWDG_CFGR` | `0x40002C04` | `0x04` | 配置（`EWI`、`WDGTB`、窗口 `W[6:0]`） | `0x007F` |
| `R16_WWDG_STATR` | `0x40002C08` | `0x08` | 状态（`EWIF`） | `0x0000` |

### 2.3 `R16_WWDG_CTLR`（`0x00`）

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[15:8]` | Reserved | RO | — | 0 |
| 7 | **`WDGA`** | RW1 | 启动看门狗；软件置 1，只由复位清 | 0 |
| `[6:0]` | **`T[6:0]`** | RW | 7 位计数器：每 `4096×2^WDGTB` 个 PCLK1 自减 1；`0x40 → 0x3F` 时复位 | `0x7F` |

### 2.4 `R16_WWDG_CFGR`（`0x04`）

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[15:10]` | Reserved | RO | — | 0 |
| 9 | **`EWI`** | RW1 | 提前唤醒中断使能（仅复位清） | 0 |
| `[8:7]` | **`WDGTB[1:0]`** | RW | 时钟分频：`00`=÷1 / `01`=÷2 / `10`=÷4 / `11`=÷8 | `00b` |
| `[6:0]` | **`W[6:0]`** | RW | 窗口值：喂狗仅在 **`T < W` 且 `T > 0x3F`** 时允许 | `0x7F` |

### 2.5 `R16_WWDG_STATR`（`0x08`）

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| `[15:1]` | Reserved | WO | — |
| 0 | **`EWIF`** | RW0 | 计数器到 `0x40` 时硬件置位（即便 `EWI=0` 也会置位）；**必须软件清** |

### 2.6 超时公式

$$
T_\text{timeout} = \frac{\text{PCLK1}}{4096 \cdot 2^{\text{WDGTB}}} \cdot (T_{[5:0]} + 1)
$$

例：PCLK1 = 36 MHz，`WDGTB=00`、`T=0x7F` → `4096 / 36 MHz × 64 ≈ 7.28 ms`。

> 喂狗**不是**重新写 `WDGA`，而是**写 `T[6:0]`**；软件写 `T[6]=0` 等效于**软件复位**。

## 3. 与调试、RCC

- **调试支持（第 34 章）**：`DBG_CR` 中的 `DBG_IWDG_STOP` / `DBG_WWDG_STOP` 位决定调试暂停时是否冻结计数器。
- **RCC 使能**：
  - IWDG 无需额外使能时钟（LSI 自由运行）；由 `RCC_CSR.LSION` / `LSIRDY` 监控；
  - WWDG 在 `RCC_APB1PCENR.WWDGEN(bit11)` 启用。
