# GPIO、AFIO 寄存器位域详述

**来源**：《CH32FV2x_V3xRM》**第 10 章**；表 **10-47**、**10-48**。  
**原文**：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)。  
**说明**：除非特别说明，**GPIO/AFIO 寄存器须以 32 位字访问**。

---

## 1. GPIO 端口基址（表 10-47）

| 端口 | 基址 |
|------|------|
| PA | `0x40010800` |
| PB | `0x40010C00` |
| PC | `0x40011000` |
| PD | `0x40011400` |
| PE | `0x40011800` |

带 **PF/PG** 的封装见数据手册；手册表 10-47 以 A~E 为主。

每个端口寄存器布局相同（相对基址）：

| 偏移 | 寄存器 | 复位值（典型） |
|------|--------|----------------|
| `+0x00` | `GPIOx_CFGLR` | `0x44444444` |
| `+0x04` | `GPIOx_CFGHR` | `0x44444444` |
| `+0x08` | `GPIOx_INDR` | 引脚态相关 |
| `+0x0C` | `GPIOx_OUTDR` | `0x00000000` |
| `+0x10` | `GPIOx_BSHR` | `0x00000000` |
| `+0x14` | `GPIOx_BCR` | `0x00000000` |
| `+0x18` | `GPIOx_LCKR` | `0x00000000` |

## 2. `GPIOx_CFGLR` / `GPIOx_CFGHR`（配置：引脚 0~7 / 8~15）

每引脚占 **4 位**：低 2 位 **`MODEy[1:0]`**，高 2 位 **`CNFy[1:0]`**。

### 2.1 `MODE`（输入/输出与速度）

| MODE[1:0] | 含义 |
|-----------|------|
| `00` | 输入模式 |
| `01` | 输出，最大 **10MHz** |
| `10` | 输出，最大 **2MHz** |
| `11` | 输出，最大 **50MHz** |

### 2.2 `CNF`（在 **输入** 且 `MODE=00` 时）

| CNF[1:0] | 含义 |
|----------|------|
| `00` | 模拟输入 |
| `01` | 浮空输入 |
| `10` | 上/下拉输入（上拉或下拉由 **ODR** 对应位选择：0=下拉，1=上拉） |
| `11` | 保留 |

### 2.3 `CNF`（在 **输出** 且 `MODE≠00` 时）

| CNF[1:0] | 含义 |
|----------|------|
| `00` | 通用推挽输出 |
| `01` | 通用开漏输出 |
| `10` | 复用推挽输出 |
| `11` | 复用开漏输出 |

---

## 3. `GPIOx_INDR`（输入数据，偏移 `0x08`）

| 位域 | 名 | 访问 | 说明 |
|------|-----|------|------|
| `[31:16]` | Reserved | RO | 保留 0 |
| `[15:0]` | `IDRy` | RO | 只读，建议 **16 位读**；为各引脚 **高/低** 电平 |

---

## 4. `GPIOx_OUTDR`（输出数据，偏移 `0x0C`）

| 位域 | 名 | 访问 | 说明 |
|------|-----|------|------|
| `[31:16]` | Reserved | RO | 0 |
| `[15:0]` | `ODRy` | RW | 输出模式：输出电平；**上拉输入** 时 0=下拉、1=上拉 |

---

## 5. `GPIOx_BSHR`（置位/清除，偏移 `0x10`）

| 位域 | 名 | 访问 | 说明 |
|------|-----|------|------|
| `[31:16]` | `BRy` | WO | 写 1 清对应 **OUTDR**；写 0 无影响；**16 位访问** |
| `[15:0]` | `BSy` | WO | 写 1 置位对应 **OUTDR**；**同周期既置又清时 BS 优先** |

---

## 6. `GPIOx_BCR`（仅清除，偏移 `0x14`）

| 位域 | 名 | 访问 | 说明 |
|------|-----|------|------|
| `[31:16]` | Reserved | RO | 0 |
| `[15:0]` | `BRy` | WO | 写 1 清 **OUTDR** 对应位 |

---

## 7. `GPIOx_LCKR`（配置锁定，偏移 `0x18`）

| 位域 | 名 | 访问 | 说明 |
|------|-----|------|------|
| `[31:17]` | Reserved | RO | 0 |
| `16` | **LCKK** | RW | 锁定键；**序列为：写1→写0→写1→读0→读1** 激活锁定 |
| `[15:0]` | **LCKy** | RW | 1=锁定该引脚 **CFGLR/CFGHR** 配置；**LCKK 锁全局前**可改 |

---

## 8. AFIO（表 10-48，基址 `0x40010000`）

| 偏移 | 寄存器 | 说明 |
|------|--------|------|
| `0x00` | `R32_AFIO_ECR` | 事件输出 **EVOE**、**PORT[2:0]**、**PIN[3:0]**（EVENTOUT 到指定 Px 引脚） |
| `0x04` | `R32_AFIO_PCFR1` | **重映射 1**：SPI1、I2C1、USART1/2/3、TIM1/2/3/4/5、CAN1/2、ETH、MII/RMII、**SW_CFG[2:0]**（**SWD 关闭=100**）、PTP PPS、SPI3、TIM2_ITR1 等 |
| `0x08` / `0x0C` / `0x10` / `0x14` | `R32_AFIO_EXTICR1` / `2` / `3` / `4` | **每 4 位** `EXTIx[3:0]` 选择端口：`0000`=PA / `0001`=PB / `0010`=PC / `0011`=PD / `0100`=PE。**`EXTICR1` 管 `EXTI0..3`、`EXTICR2` 管 `EXTI4..7`、`EXTICR3` 管 `EXTI8..11`、`EXTICR4` 管 `EXTI12..15`** |
| `0x1C` | `R32_AFIO_PCFR2` | 重映射 2（含部分 USART1 高位、USART4/5/6/7/8 等，见手册与型号） |

### 8.1 `AFIO_PCFR1` 位域（**10.3.2.2** 全表）

| 位 | 名称 | 作用（适用型号见手册原文注） |
|----|------|------------------------------|
| 31 | Reserved | — |
| 30 | `PTP_PPS_RM` | `0`=不输出；`1`=PTP PPS 输出到 **PB5**（**V20x_D8C/V30x_D8C/V31x_D8C**） |
| 29 | `TIM2ITR1_RM` | `0`=TIM2_ITR1 连以太网 PTP；`1`=连 USB OTG FS SOF（**全系列**） |
| 28 | `SPI3_RM` | `0`=默认（NSS/PA15，SCK/PB3，MISO/PB4，MOSI/PB5）；`1`=重映射（NSS/PA4，SCK/PC10，MISO/PC11，MOSI/PC12）（**V30x_D8/D8C、V31x_D8C、F20x_D8/D8C**） |
| 27 | Reserved | — |
| `[26:24]` | `SW_CFG[2:0]` | **调试口**：`0xx`=SWD 启用；**`100`=关 SWD，引脚作 GPIO**（慎用） |
| 23 | `MII_RMII_SEL` | `0`=MII；`1`=RMII（**F20x_D8C/D8W、V30x_D8C、V31x_D8C、V20x_D8/D8W**） |
| 22 | `CAN2_RM` | `0`=PB12/PB13；`1`=PB5/PB6（**V30x_D8/D8C、V31x_D8C、F20x_D8/D8C、V20x_D8**） |
| 21 | `ETH_RM` | `0`=RX 默认（PA7/PC4/PC5/PB0/PB1）；`1`=RX 重映射（PD8/PD9/PD10/PD11/PD12）。**仅适用 `CH32F207VCT6` / `CH32V307VCT6` / `CH32V317VCT6`（LQFP100 封装）** |
| 20 | `ADC2_ETRGREG_RM` | `0`=ADC2 规则触发连 EXTI11；`1`=连 TIM8_TRGO（**F20x_D8/D8C、V30x/V31x 全系列**） |
| 19 | `ADC2_ETRGINJ_RM` | `0`=ADC2 注入触发连 EXTI15；`1`=连 TIM8_CH4 |
| 18 | `ADC1_ETRGREG_RM` | 同上，对 ADC1 |
| 17 | `ADC1_ETRGINJ_RM` | 同上，对 ADC1 |
| 16 | `TIM5CH4_RM` | `0`=默认；`1`=TIM5_CH4 映射至 **LSI** 内部时钟（**V20x/V30x/V31x 全系列**） |
| 15 | `PD0PD1_RM`（=`PD01_RM`） | `0`=晶振引脚；`1`=作 GPIO（适用范围见手册注；**V203RBT6 不支持**） |
| `[14:13]` | `CAN1_RM[1:0]` | `00`=PA11/PA12；`10`=PB8/PB9；`11`=PD0/PD1；`01` 保留 |
| 12 | `TIM4_RM` | `0`=PB6..9；`1`=PD12..15（**仅 VCT6 LQFP100**） |
| `[11:10]` | `TIM3_RM[1:0]` | `00`=默认 / `10`=部分 / `11`=完全（**64 脚及以上封装**） |
| `[9:8]` | `TIM2_RM[1:0]` | 4 组映射（含 ETR 不同引脚） |
| `[7:6]` | `TIM1_RM[1:0]` | `00`=默认/`01`=部分/`11`=完全（完全**仅 VCT6 LQFP100**）；`10` 保留 |
| `[5:4]` | `USART3_RM[1:0]` | `00`=默认 / `01`=部分 / `10`=部分2（**D8/D8C 批号限定**）/ `11`=完全（**仅 VCT6 LQFP100**） |
| 3 | `USART2_RM` | `0`=PA0..PA4；`1`=PD3..PD7（**V20x_D6/F20x_D6 只支持 `0`**） |
| 2 | `USART1_RM` | **与 `PCFR2.USART1_RM1 (bit26)` 组合** 为 2 位映射选择（`00`/`01` 为全系列；`10`/`11` 仅部分型号） |
| 1 | `I2C1_RM` | `0`=PB6/PB7；`1`=PB8/PB9 |
| 0 | `SPI1_RM` | `0`=PA4..PA7；`1`=PA15/PB3..PB5 |

> **完整批号/型号限定** 请对照手册 **10.3.2.2**（本表列出的是 **V2.4 手册** 摘要）。
