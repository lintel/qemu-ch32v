# EXTI、PFIC、STK（SysTick/系统计数）寄存器位域详述

**来源**：《CH32FV2x_V3xRM》第 9 章；原文：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)。  
**适用**：CH32F20x / V20x / V30x / V31x（RISC-V 子系列为 **PFIC + STK**，非 ARM NVIC）。

---

## 1. EXTI（外部中断/事件控制器）

**基址**：`0x40010400`（表 9-4）

| 寄存器名 | 偏移 | 访问 | 简述 |
|----------|------|------|------|
| `R32_EXTI_INTENR` | `0x00` | RW | 中断使能 `MR[21:0]`：0 屏蔽，1 使能该线 |
| `R32_EXTI_EVENR` | `0x04` | RW | 事件使能，同结构 |
| `R32_EXTI_RTENR` | `0x08` | RW | 上升沿触发使能 |
| `R32_EXTI_FTENR` | `0x0C` | RW | 下降沿触发使能 |
| `R32_EXTI_SWIEVR` | `0x10` | RW | 软件触发事件/中断 |
| `R32_EXTI_INTFR` | `0x14` | RW1 | 中断挂起标志 `IFx`，**写 1 清除** |

**说明**：各 `MRx` / 线号与 **表 9-3（EXTI 中断映射）** 一致；线 16~ 与 USB 唤醒、HSI、RTC、以太网、32K 校准等复用，见手册 **9.4** 节及您的具体型号。

**线到引脚**：由 **AFIO `EXTICR1`～`EXTICR4`** 选择端口（PA~PE），见 [10-GPIO-AFIO-寄存器位域详述.md](./10-GPIO-AFIO-寄存器位域详述.md)。

## 2. PFIC（可编程快速中断控制器）

**基址**：`0xE000E000`（表 9-5）

### 2.1 常用寄存器地址一览

| 名称 | 地址 | 作用 |
|------|------|------|
| `R32_PFIC_ISR1`～`ISR4` | `0xE000E000`～`0x0C` | 中断**已使能**状态（只读组） |
| `R32_PFIC_IPR1`～`IPR4` | `0xE000E020`～`0x2C` | **挂起**状态 |
| `R32_PFIC_ITHRESDR` | `0xE000E040` | 优先级阈值 |
| `R32_PFIC_CFGR` | `0xE000E048` | 中断配置 |
| `R32_PFIC_GISR` | `0xE000E04C` | 全局状态 |
| `R32_PFIC_VTFIDR` | `0xE000E050` | VTF 中断 ID |
| `R32_PFIC_VTFADDRR0`～`3` | `0xE000E060`～`0x6C` | VTF 向量地址 |
| `R32_PFIC_IENR1`～`IENR4` | `0xE000E100`～`0x10C` | **置位**使能（写 1 使能） |
| `R32_PFIC_IRER1`～`IRER4` | `0xE000E180`～`0x18C` | **清除**使能 |
| `R32_PFIC_IPSR1`～`IPSR4` | `0xE000E200`～`0x20C` | **置位**挂起 |
| `R32_PFIC_IPRR1`～`IPRR4` | `0xE000E280`～`0x28C` | **清除**挂起 |
| `R32_PFIC_IACTR1`～`IACTR4` | `0xE000E300`～`0x30C` | 激活状态 |
| `R32_PFIC_IPRIORx` | `0xE000E400` 起 | 每中断 1 字节优先级（见手册） |
| `R32_PFIC_SCTLR` | `0xE000ED10` | 系统控制 |

### 2.2 `PFIC_ISR1`（示例：偏移 0x00）

| 位域 | 名称 | 访问 | 描述 |
|------|------|------|------|
| `[31:12]` | Reserved | RO | 保留 |
| `[11:4]` | INTENSTA[11:4] | RO | 11#～4# 中断当前是否已使能 |
| `[3:2]` | INTENSTA[3:2] | RO | 3#～2# |
| `[1:0]` | Reserved | RO | 保留 |

**手册注**：NMI、HardFault、ECALL-M/U、BREAKPOINT 等默认总使能；对 `IENR` 写前/配合全局中断屏蔽时，需追加一条 **`fence.i`** 与 CSR 同步（见 **9.5.2** 文中原注）。

## 3. STK（RISC-V 青稞 64 位系统计数 / 与 ARM SysTick 对应功能）

**基址**：`0xE000F000`（表 9-6；另见表 9-7 中 ARM 命名说明，**以 9-6 为准**）

| 寄存器名 | 偏移 | 描述 |
|----------|------|------|
| `R32_STK_CTLR` | `0x00` | 控制：含 **INIT**、**MODE**、**STRE**、**STCLK**、**STIE**、**SWIE** 等（软件中断触发等） |
| `R32_STK_SR` | `0x04` | 状态 |
| `R32_STK_CNTL` | `0x08` | 计数器 **低 32 位** |
| `R32_STK_CNTH` | `0x0C` | 计数器 **高 32 位**（与 CNTL 组成 64 位计数） |
| `R32_STK_CMPLR` | `0x10` | 比较值低 32 位 |
| `R32_STK_CMPHR` | `0x14` | 比较值高 32 位 |

**使用注意**：ch32fun 中 `SysTick` 外设常映射到此块；与 **CH32V003** 上仅 32 位 CNT 的 `SysTick_Type` 可能不同，以头文件与手册 **9.5.5/9.5.6** 为准。
