# FLASH（闪存与用户选择字）寄存器位域详述

**来源**：《CH32F/V20x_V30x_V31x 系列应用手册》V2.4（[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)），**第 32 章「闪存及用户选择字（FLASH）」**（PDF **p522–534**）。  
**适用**：CH32F20x / V20x / V30x / V31x **全系列**。

---

## 1. 闪存组织（表 32-1，以 VCT6 为例）

| 区域 | 地址范围 | 大小 | 备注 |
|------|----------|------|------|
| **主存储器** | `0x08000000 – 0x08077FFF` | 以 **页** 组织，每页 **256 B**（**1920 页**，即 **480 KB** 上限） | 以 **4KB（16 页）** 为单位做写保护划分 |
| **系统引导代码（BOOT）** | `0x1FFF8000 – 0x1FFFEFFF` | 28 KB | 出厂锁定，用户不可访问 |
| **用户选择字** | `0x1FFFF800 – 0x1FFFF87F` | 128 B | 可擦除/编程 |

> **主频限制**：执行 FLASH 操作时**系统主频 ≤ 120 MHz**；若必须 > 120 MHz，**先 HCLK ÷ 2** 再操作；**`FLASH_CTLR.SCKMOD(bit25)`** 可选 FLASH 访问时钟 = SYSCLK 或 SYSCLK/2（默认 /2）。

### 1.1 两种编程/擦除方式

- **标准编程（PG）**：单次 **2 字节** 写；单次 **4 KB 扇区** 或**整片**擦除；
- **快速编程（FTPG / FTER）**：**256 B 页**编程；256 B 页擦除 / **32 KB** 块擦除 / 整片擦除；需 `MODEKEYR` 解锁。

## 3. 位域

### 3.1 `R32_FLASH_KEYR`（`0x04`，**WO**）

写入以下序列解锁 FPEC（锁定位 `CTLR.LOCK` 被硬件清 0）：

- `KEY1 = 0x45670123`
- `KEY2 = 0xCDEF89AB`

另有 `RDPRT 键 = 0x000000A5`（用于读保护相关）。错误序列会锁死 FPEC 至下次系统复位。

### 3.2 `R32_FLASH_OBKEYR`（`0x08`，**WO**）

与 `KEYR` 同一序列 `KEY1 / KEY2`，成功后 `CTLR.OBWRE=1`，解锁用户选择字。

### 3.3 `R32_FLASH_STATR`（`0x0C`）— 状态

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| `[31:8]` | Reserved | RO | — |
| 7 | **`EHMODS`** | RO | FLASH **增强读模式** 已启用 |
| 5 | **`EOP`** | RW1 | 操作成功结束（每次擦写后置位） |
| 4 | **`WRPRTERR`** | RW1 | 写保护错误（对被保护地址编程） |
| 1 | **`WRBSY`** | RO | 快速页编程时**数据正在写入**；完成后硬件自清 |
| 0 | **`BSY`** | RO | FLASH 忙；**为 1 时禁止写任何寄存器** |

### 3.4 `R32_FLASH_CTLR`（`0x10`，复位 `0x00008080`）— 配置

| 位 | 名称 | 访问 | 描述 |
|----|------|------|------|
| 25 | **`SCKMOD`** | RW | `0`=FLASH 访问时钟 = SYSCLK/2（默认）；`1`=SYSCLK（不超 60 MHz） |
| 24 | **`EHMOD`** | RW | 增强读模式：`1`=使能（代码运行于 FLASH 时提速） |
| 22 | **`RSENACT`** | WO | 退出增强读（需先 `EHMOD=0`，再 `RSENACT=1`），硬件自清 |
| 21 | **`PGSTRT`** | RW0 | 启动一次**快速页**编程 |
| 18 | **`BER32`** | RW | 32 KB 块擦除（快速） |
| 17 | **`FTER`** | RW | 快速 256 B 页擦除 |
| 16 | **`FTPG`** | RW | 快速页编程 |
| 15 | **`FLOCK`** | RW1 | 快速编程锁；`MODEKEYR` 解锁后由硬件清 0；软件写 1 重新上锁 |
| 12 | **`EOPIE`** | RW | `STATR.EOP` 中断使能 |
| 10 | **`ERRIE`** | RW | 错误中断使能（`WRPRTERR` 等） |
| 9  | **`OBWRE`** | RW0 | 用户选择字写使能（`OBKEYR` 解锁后硬件置 1） |
| 7  | **`LOCK`** | RW1 | FPEC 锁；硬件清 0 表示解锁；软件写 1 重新上锁 |
| 6  | **`STRT`** | RW1 | 启动一次**标准**擦除；硬件自清 |
| 5  | **`OBER`** | RW | 用户选择字擦除 |
| 4  | **`OBPG`** | RW | 用户选择字编程 |
| 2  | **`MER`** | RW | 整片擦除 |
| 1  | **`PER`** | RW | 标准 4 KB 页擦除 |
| 0  | **`PG`** | RW | 标准编程使能（写半字触发） |

### 3.5 `R32_FLASH_ADDR`（`0x14`，**WO**）

编程/擦除的起始地址；`BSY=1` 时禁止写。

### 3.6 `R32_FLASH_OBR`（`0x1C`，**RO**）— 选择字映射

系统复位后从选择字区（`0x1FFFF800`）自动加载。

| 位 | 名称 | 描述 |
|----|------|------|
| `[9:7]` | **`RAM_CODE_MOD[2:0]`** | CODE/RAM 切片（见下表） |
| 4 | `STANDYRST` | 待机模式下是否系统复位 |
| 3 | `STOPRST`   | 停机模式下是否系统复位 |
| 2 | `IWDGSW`   | 独立看门狗：`0`=硬件启动；`1`=软件启动 |
| 1 | `RDPRT`    | 读保护：`1`=有效 |
| 0 | `OBERR`    | 选择字与反码不匹配错误 |

**`RAM_CODE_MOD` 切片**（**V303RC/V307RC/V307WC/V307VC/V303VC/F203RC/F203VC/F207VC/V317 系列**）：

| 编码 | CODE | RAM |
|------|------|-----|
| `00x` | 192 KB | 128 KB |
| `01x` | 224 KB | 96 KB |
| `10x` | 256 KB | 64 KB |
| `110` | 128 KB | 192 KB（**仅批号倒数第六位 ≠ 0**） |
| `111` | 288 KB | 32 KB |

**V20x_D8/D8W、F20x_D8W**：

| 编码 | CODE | RAM |
|------|------|-----|
| `00x` | 128 KB | 64 KB |
| `01x` | 144 KB | 48 KB |
| `1xx` | 160 KB | 32 KB |

### 3.7 `R32_FLASH_WPR`（`0x20`，**RO**）

每位代表 **4 KB（16 页）**的写保护：`0`=保护、`1`=可写。上电从选择字加载。

### 3.8 `R32_FLASH_MODEKEYR`（`0x24`，**WO**）

`KEY1 = 0x45670123` + `KEY2 = 0xCDEF89AB` 解锁**快速编程模式**（清 `CTLR.FLOCK`）。

## 4. 用户选择字（表 32-3 / 32-4）

**选择字字节格式**：`[31:24]=字节1反码 | [23:16]=字节1 | [15:8]=字节0反码 | [7:0]=字节0`（每字节带反码校验）。

| 地址 | `[31:24]` | `[23:16]` | `[15:8]` | `[7:0]` |
|------|-----------|-----------|----------|---------|
| `0x1FFFF800` | `nUSER` | `USER` | `nRDPR` | **`RDPR`** |
| `0x1FFFF804` | `nData1` | `Data1` | `nData0` | `Data0` |
| `0x1FFFF808` | `nWRPR1` | `WRPR1` | `nWRPR0` | `WRPR0` |
| `0x1FFFF80C` | `nWRPR3` | `WRPR3` | `nWRPR2` | `WRPR2` |

- **`RDPR`**：`0xA5`=**非读保护**；其他值=**读保护**（0~15 页自动写保护，不受 `WRPR` 控制）。
- **`USER[7:5] = RAM_CODE_MOD`** + `[4:3]` Reserved(`11b`) + `[2] STANDYRST`(`1`=不复位) + `[1] STOPRST`(`1`=不复位) + `[0] IWDGSW`(`1`=软件 IWDG)。
- **`WRPR0..3`**：控制 480 KB 主存储器的写保护，**每位管 4 KB（16 页）**：
  - `WRPR0` → 页 0–7（每位对应 8 页？实际编码见手册；**粒度为 4 KB/扇区**）；
  - `WRPR1` → 页 8–15；`WRPR2` → 页 16–23；`WRPR3` 位 0–6 → 页 24–30，位 7 → 页 31–119。

### 4.1 解除读保护

```
1. 擦除整个用户选择字
2. 编程正确的 RDPR=0xA5（系统自动整片擦除主存储区！）
3. 上电复位，加载新的 RDPR
```

### 4.2 解除写保护

同上步骤，重新加载 `WRPR[3:0]`。

## 5. 操作示例

### 5.1 标准编程（半字）

```
LOCK? → KEY1/KEY2 解锁
CTLR.PG = 1
*(uint16_t*)addr = half;        // 每次 2 字节
等 BSY=0，读 EOP；
CTLR.PG = 0
```

### 5.2 快速编程（256 B 页）

```
KEY1/KEY2 → LOCK=0
MODEKEYR: KEY1/KEY2 → FLOCK=0
CTLR.FTPG = 1
按 32 次 uint64 写满一页 256 B（或按 WCH 例程的 `Flash_BufLoad`）
CTLR.PGSTRT = 1  // 启动编程
等 BSY=0；CTLR.FTPG = 0
```

### 5.3 标准擦除（4 KB 页）

```
LOCK=0 → CTLR.PER=1
FAR = 页起始地址
CTLR.STRT = 1
等 BSY=0；CTLR.PER=0
```
