# SPI / I2S（SPI1/2/3）寄存器位域详述

**来源**：《CH32FV2x_V3xRM》**第 20 章**；表 **20-1**～**20-3** 与 **20.4.x**。  
**原文**：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)（V2.4 约 **PDF 第 291–310+ 页**）。  
**头文件**：`SPI_TypeDef` 与**偏移**一致；**I2S** 使用 **`I2S_CFGR`、`I2SPR`（仅 SPI2/3）**。

## 1. 表 20-1 / 20-2 / 20-3 基址与全寄存器

### SPI1（表 20-1）

| 地址 | 寄存器 | 典型复位 |
|------|--------|----------|
| `0x40013000` | `R16_SPI1_CTLR1` | `0x0000` |
| `0x40013004` | `R16_SPI1_CTLR2` | `0x0000` |
| `0x40013008` | `R16_SPI1_STATR` | `0x0002` |
| `0x4001300C` | `R16_SPI1_DATAR` | `0x0000` |
| `0x40013010` | `R16_SPI1_CRCR` | `0x0007` |
| `0x40013014` | `R16_SPI1_RCRCR` | `0x0000` |
| `0x40013018` | `R16_SPI1_TCRCR` | `0x0000` |
| `0x4001301C` | `R16_SPI1_I2S_CFGR` | `0x0000` |
| `0x40013024` | `R16_SPI1_HSCR` | `0x0000` |

> **SPI1 无 `I2SPR`** 行于表 20-1；**HSCR` 在 `+0x24`（距 `I2S_CFGR` 有 4 字节孔）** — 以 PDF 全表为准。

### SPI2（`0x40003800`）、SPI3（`0x40003C00`）

- 在 **I2S_CFGR` 后增加** **`R16_SPIx_I2SPR`（+0x20）** 与 **`HSCR`（+0x24）**；布局见表 **20-2、20-3**。

## 2. `SPIx_CTLR1`（**20.4.1 摘要**）

| 位 | 名 | 说明 |
|----|-----|------|
| 15 | **BIDIMODE** / 14 **BIDIOE** | 单线半双工方向 |
| 13 | **CRCEN** / 12 **CRCNEXT** | 硬件 CRC |
| 11 | **DFF** | 0=8 位、1=16 位数据 |
| 10 | **RXONLY** | 只收 |
| 9–8 | **SSM, SSI** | 从机片选内/外 |
| 7 | **LSBFIRST** | MSB/LSB 先发 |
| 6 | **SPE** | 使能 |
| [5:3] | **BR[2:0]** | 分频；**HSCR 的 HSRXEN=1 时**分频表切换（**手册 20.4.1 注**） |
| 2 | **MSTR** | 主/从 |
| 1–0 | **CPOL, CPHA** | 同 STM32 SPI 约定 |

## 3. `CTLR2`、`STATR`、`I2S_CFGR` / `I2SPR`

- **CTLR2**：`SSOE`、`TXDIE`/`ERRIE`/`RXNE`/`TXE` 中断、**DMA 收发**等。  
- **STATR**：`BSY`、`OVR`、**RXNE/TXE**、双缓冲相关（以手册位图为准）。  
- **I2S 模式**下 **`I2S_CFGR`** 选 I2S/左对齐/左/右/PCM 与 **I2S 全双工/主从/时钟**；**`I2SPR`** 设置 **I2S 分频/奇系数 MCK 输出**。

## 4. `HSCR`（高速控制）

- **WCH 扩展**高速 SPI 时序；与 **BR** 表切换、**收发方向** 见 20.3.8/20.4.8 类小节。

---

## 5. 与 TIM / DMA

- **I2S** 的 DMA 与 **I2S 时序/WS** 见 **20.3.9**；**CRC** 在 I2S 时不可用（**原文**说明）。
