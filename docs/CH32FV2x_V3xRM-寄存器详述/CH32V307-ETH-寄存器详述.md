# CH32V307 / CH32V317 / CH32F207 — 以太网寄存器位域详述

**来源**：《CH32F/V20x_V30x_V31x 系列应用手册》V2.4（[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)），**第 27 章「以太网收发器（ETH）」**。  
**适用**：**本节 27.1** 明确覆盖 **CH32F207、CH32V307、CH32V317**（千兆/百兆/十兆可切换的 MAC + DMA + MMC + PTP + 内部 10M 或 10/100M PHY）。  
**配套文档**：应用级与板级见 [../CH32V30X/CH32V307-ETH.md](../CH32V30X/CH32V307-ETH.md)；描述符对照见本文 §5；V203 系列（ETH10M）**不是** 此寄存器映射，另见 [CH32V203-ETH-寄存器详述.md](./CH32V203-ETH-寄存器详述.md)。

> **关键区分**：手册 **第 27 章** 同时容纳两种以太网外设——  
> - **27.1**（本文对应）：CH32V307/V317/F207 的 **千兆/MAC+DMA+MMC+PTP** 全功能控制器，`R32_ETH_*` 命名，**基址 `0x4002_8000`（MAC/MMC/PTP）与 `0x4002_9000`（DMA）**；  
> - **27.2**：CH32V203/V208/F208 的 **10M 专用**以太网控制器，`R8_/R16_/R32_ETH_*` 混合命名，**基址 `0x4002_8003~0x4002_802C`**，**完全不同**。

---

## 1. 主要特征与子模块（27.1.1）

- **MAC**：支持 MII/RMII/RGMII；**10/100/1000 Mbps** 全/半双工；VLAN、CRC/SFD 自动、IPv4/ICMP/TCP/UDP 校验卸载、哈希 + 完美目标地址过滤、魔法帧/自定义唤醒帧；**双 SMI（RGMII 与 MII 各一套）**；CH32V307/F207 可选**内置 10M PHY** 或**外置 1G PHY**；CH32V317 为 **内置 10/100M PHY**。
- **DMA**：**32 位宽 MAC 专用 DMA**，描述符**链式或环式**，OWN 切换，支持收发完成中断等。
- **MMC**：硬件统计计数器 + 中断，支持冻结/读时复位/回转停止。
- **PTP**：**IEEE 1588**；**32 位秒 + 32 位亚秒**（符号 + 30 位）；**粗调/精调**两种时间调节；目标时间触发中断；**PPS 输出**。
- **内部 10M PHY**（仅 V307/F207）：10BASE-T、MDIX 自翻转、P/N 极性翻转、软复位、数据环回、半/全双工；**时钟为 PLL3 60MHz**，使用前须置 `EXTEN_ETH_10M_EN` 并完成 RCC 配置（详见 27.1.4.4.1 与 27.1.4.5.1）。
- **内部 10/100M PHY**（仅 V317）：10BASE-T + 100BASE-TX + 自动协商；RMII；Auto-MDIX；WOL；中断；双 LED 指示。

### 3.11 MAC 地址寄存器 0 / 1 / 2 / 3（偏移 `0x40`/`0x48`/`0x50`/`0x58`）

- **`MACA0`**：上电复位值 **`0x8000_FFFF / 0xFFFF_FFFF`**，`MACA0HR[31]` 恒为 `1`（`MO`）；通常作为本机地址。
- **`MACA1/2/3`（HR）**：`AE`（过滤使能，31）/ `SA`（源地址对比，30）/ `MBC[5:0]`（按字节屏蔽，29:24，**[29:27] 必须同时开关**）+ 高 16 位 `MACAxH[15:0]`；`AE=0` 时该地址不参与过滤。

### 4.1 `R32_ETH_MMCCR`（偏移 `0x0100`）

| 位 | 名称 | 描述 |
|----|------|------|

| 2 | `ROR` | 读时清零 |
| 1 | `CSR` | 计数到最大值后停止（不回转） |
| 0 | `CR`（RW1Z） | 复位所有计数，一周期自清 |

### 4.2 中断/屏蔽

- `MMCRIR`（`0x0104`）：`RGUFS`（位 17，接收好帧过半）、`RFCES`（位 5，CRC 错帧过半）。
- `MMCTIR`（`0x0108`）：`TGFS`（位 21，发送帧过半）。
- `MMCRIMR`（`0x010C`）、`MMCTIMR`（`0x0110`）：对应屏蔽位 `RGUFM`/`RFCEM`/`TGFM`。

### 4.3 计数器

- `MMCTGFSCCR`（`0x014C`）：半双工下单冲突后发送好帧数（只读 32 位）。
- `MMCTGFMSCCR`（`0x0150`）：多冲突后发送好帧数。
- `MMCTGFCR`（`0x0168`）：总发送好帧。
- `MMCRFCECR`（`0x0194`）：接收 CRC 错帧。
- `MMCRFAECR`（`0x0198`）：接收对齐错误帧。
- `MMCRGUFCR`（`0x01C4`）：接收好单播帧。

## 6. DMA 位域（27.1.8.4）

### 6.1 `R32_ETH_DMABMR` — DMA 总线模式（偏移 `0x1000`，复位 `0x00000001`）

| 位 | 名称 | 描述 |
|----|------|------|
| `[6:2]` | `DSL[4:0]` | 描述符跳跃长度（字为单位；环式时 `0` 表示紧邻排列） |
| 0 | `SR` | 软件复位：复位整个 MAC 子系统，完成后自清；清零后才可写其它 MAC 寄存器 |

### 6.2 `R32_ETH_DMATPDR` / `DMARPDR` — 发送/接收查询（偏移 `0x1004`/`0x1008`）

写任意值即重启被暂停的发送/接收流程，写入值硬件自动清零。

### 6.3 `R32_ETH_DMARDLAR` / `DMATDLAR` — 描述符数组首址（偏移 `0x100C`/`0x1010`）

**16 字节对齐**（低 4 位应为 0）。

### 6.4 `R32_ETH_DMASR` — DMA 状态（偏移 `0x1014`）

| 位 | 名称 | 访问 | 描述 |

| 31 | `PLS` | RW1Z | 内部 10M PHY 链路状态变化（链接上或断开） |
| 30 | Reserved | RO | — |
| 29 | `TSTS` | RO | PTP 中断汇总 |
| 28 | `PMTS` | RO | PMT 中断汇总 |

| 26 | Reserved | RO | — |
| `[25:23]` | `EBS[2:0]` | RO | 总线错误类型（仅在 `FBES` 有效时）：23 位：收/发；24 位：读/写；25 位：描述符/数据 |

| 1 | `TPSS` | RW1Z | 发送流程停止 |

## 7. DMA 描述符（27.1.6.2，表 27-11～21）

### 7.1 发送 `TDes0`（**32 位，控制/状态**）

| 位 | 名称 | 描述 |
|----|------|------|
| 31 | `OWN` | 0=CPU；1=DMA；硬件发完写 0 |
| 30 | `IC` | 发送完成中断（`DMASR.TS`） |
| 29 | `LS` | 末段：本描述符含帧结尾 |
| 28 | `FS` | 首段：本描述符含帧开头 |
| 27 | `DC` | 禁止自动 CRC（`FS=1` 时生效；`DP` 优先级更高） |
| 26 | `DP` | 禁止自动填充；为 0 时 DMA 自动填 64 B 及 CRC |
| 25 | `TTE` | 启用 IEEE 1588 时间戳发送（须 `PTPTSCR.TSE=1` 且 `FS=1`） |
| `[23:22]` | `CIC[1:0]` | 00=无；01=IP 头；10=保留；11=IP 头 + 有效负载（伪报头也算） |
| 21 | `TER` | 发送描述符环末端；下次回数组头部 |
| 20 | `TCH` | 链式：`TDes3` 为下一描述符地址（`FS=1` 才有效；`TER` 优先级高） |
| 17 | `TSS` | 发送时间戳已捕获（存于 `TDes2/TDes3`） |
| 16 | `IHE` | IP 报头错（IPv4 头长/IPv6 40 B 校验） |
| 15 | `ES` | 错误汇总（UF/IPE/FF/JT/IHE 任一） |
| 14 | `JT` | Jabber 超时（仅 `JD=0` 时置位） |
| 13 | `FF` | 由 CPU 命令 DMA 从 FIFO 清空帧 |
| 12 | `IPE` | IP 包头错误（长度不一致） |
| 11 | `LCA` | 载波丢失（半双工） |
| 10 | `NC` | 无载波（半双工） |
| 9 | `LCO` | 迟到冲突（半双工） |
| 8 | `EC` | 冲突过多；若 `MACCR.RD=1`，仅表示 1 次冲突（半双工） |
| 7 | `VF` | VLAN 帧 |
| `[6:3]` | `CC[3:0]` | 冲突计数；`EC=1` 时无效（半双工） |
| 2 | `EC` | 顺延过多（`MACCR.DC=1` 且顺延 > 24288 位） |
| 1 | `UF` | 发送数据下溢 |
| 0 | `DB` | 顺延指示（载波占用失败，半双工） |

### 7.2 发送 `TDes1 / TDes2 / TDes3`

- `TDes1`：`[28:16]=TBS2`，`[12:0]=TBS1`（缓冲区 2/1 字节数）。
- `TDes2`：缓冲区 1 地址；**IEEE 1588 模式**回写时间戳低 32 位（`TTSL`）。
- `TDes3`：`TCH=1` → 下一描述符地址；`TCH=0` → 缓冲区 2 地址；IEEE 1588 模式回写时间戳高 32 位（`TTSH`）。

### 7.3 接收 `RDes0`

| 位 | 名称 | 描述 |
|----|------|------|
| 31 | `OWN` | 同 TDes0 |
| 30 | `AFM` | 目标地址过滤未通过 |
| `[29:16]` | `FL[13:0]` | 帧长（含 CRC，`ES=0` 有效；`LS=1` 时为整帧长度，否则累计长度） |
| 15 | `ES` | 错误汇总（`CE/RE/RWT/IPHCE/OE/DE`） |
| 14 | `DE` | 描述符错（缓冲区装不下且 DMA 不续用下一描述符；仅 `LS=1` 有效） |
| 13 | `SAF` | 源地址过滤未通过 |
| 12 | `LE` | 长度不符（仅 `FT=1` 时有效） |
| 11 | `OE` | 接收 FIFO 溢出 |
| 10 | `VLAN` | VLAN 帧 |
| 9 | `FS` | 首描述符 |
| 8 | `LS` | 尾描述符 |
| 7 | `IPHCE` | IP 头校验和错（见表 27-18 组合） |
| 6 | `LCO` | 迟到冲突（半双工） |
| 5 | `FT` | 1=以太网封装（RFC 894）；0=IEEE 802.3（RFC 1042）。帧长 <14 B 时无效；**表 27-18** 给出 `FT/IPHCE/PCE` 的完整组合含义（如 ARP、IP 负载校验错等） |
| 4 | `RWT` | 接收看门狗超时（帧截断） |
| 3 | `RE`  | `RX_DV` 有效时 `RX_ERR` 有效 |
| 2 | `DE`  | Dribble 比特错（非 8 bit 整数倍） |
| 1 | `CE`  | CRC 错（仅 `LS=1` 有效） |
| 0 | `PCE` | TCP/UDP/ICMP 负载校验和错 |

### 7.4 接收 `RDes1 / RDes2 / RDes3`

- `RDes1`：`DIC`（31，关闭接收完成中断）；`[28:16]=RBS2`；`RER`（15，环末端）；`RCH`（14，链式）；`[12:0]=RBS1`。
- `RDes2`：缓冲区 1 地址；IEEE 1588 模式回写时间戳低 32 位（`RTSL`）。
- `RDes3`：`RCH=1` → 下一描述符；`RCH=0` → 缓冲区 2；IEEE 1588 模式回写时间戳高 32 位（`RTSH`）。

> **对齐要求**：描述符数组 **16 字节对齐**；缓冲区无对齐强制要求（建议 `1524 B` 对齐以容纳 VLAN 帧 + 4 字节余量）。

## 8. 中断（27.1.7）

- **DMA 中断入口**（`ETH_IRQn`）：位映射见 **§6.4/§6.6**，核心是 `DMAIER.NISE/AISE` + `DMASR.NIS/AIS` 两层。
- **ETH（PMT/唤醒）中断**：通过 `MACSR.PMTS` 或 `WFR/MPR` 唤醒；**专用以太网唤醒中断入口** 存在。
- **PTP 触发**：`DMASR.TSTS` 与 `MACSR.TSTS`，屏蔽位 `MACIMR.TSTIM`。

## 9. 操作流程要点（27.1.6.4）

### 9.1 发送
1. 填缓冲区 → 构造 `TDesN`（设置 `OWN=1` 等）→ 首地址写入 `DMATDLAR`；
2. `DMAOMR.ST=1` 启动发送；
3. 运行中 DMA 自动取下一描述符；`OWN=0` 或其它错误会触发 `TBUS`/`NIS`；
4. **单个帧不允许跨多个描述符**（一帧：一描述符 + 一缓冲区）。

### 9.2 接收
1. 设置缓冲区，`DMARDLAR` 指向接收描述符数组；
2. `DMAOMR.SR=1` 启动接收；
3. 处理 `DMASR.RS` → 读 `RDes0.FL` → 释放 `OWN` → 必要时写 `DMARPDR` 重启。

### 9.3 MAC/DMA 初始化顺序

```
RCC: 使能 ETH/ETHTX/ETHRX 时钟 → EXTEN: 若用内部 10M PHY 置 ETH_10M_EN → 配置 AFIO/GPIO 复用
→ DMABMR.SR=1 软复位 → 等 SR=0 → 配置 MACMIIAR（读取 PHY 状态）→ MACCR/MACFFR/MACFCR
→ DMABMR/DMAOMR → 写 MACAxHR/MACAxLR → 构造描述符 → DMATDLAR/DMARDLAR
→ DMAIER 使能所需中断 → DMAOMR.ST/SR=1 启动
```
