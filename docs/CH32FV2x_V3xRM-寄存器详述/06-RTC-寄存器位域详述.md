# RTC（实时时钟）寄存器位域详述

**来源**：《CH32F/V20x_V30x_V31x 系列应用手册》V2.4（[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)），**第 6 章「实时时钟（RTC）」**（PDF **p62–66**）。  
**适用**：CH32F20x / V20x / V30x / V31x **全系列**。

---

## 1. 主要特征与时钟源

- **32 位可编程计数器** `CNT`；
- **最高 2²⁰ 预分频因子** `PRL[19:0]`；
- **时钟源**：由 **`RCC_BDCTLR.RTCSEL[1:0]`** 选择 — `01`=LSE、`10`=LSI、`11`=HSE/分频（分频因子随型号：**D6 批号限定 ÷512/÷128；D8W/V20x_D8/D8W ÷512；D8/D8C/V30x/V31x ÷128**）；
- **三种中断**：秒（`SECF`）、闹钟（`ALRF`）、溢出（`OWF`）；
- RTC 位于**后备域**，**系统复位和待机唤醒不影响** 计数/闹钟/预分频。

---

## 2. 编程须知（6.2.3）

**读操作**：PB1 与 RTC 异步；**首次读前**需等待 `CTLRL.RSF=1` 同步；**PB1 复位/停时钟后** 需先清 `RSF`。

**写操作**必须进入**配置模式**：
1. 确保 `PWR_CTLR.DBP=1`（授权后备域写）；
2. 查询 `CTLRL.RTOFF=1` 等上次写入完成；
3. `CTLRL.CNF=1` 进入配置模式；
4. 写 `CNT/ALR/PSCR` 等；
5. 清 `CNF=0` 退出配置模式（PB1 开始真正写入）；
6. 查询 `RTOFF=1` 确认完成。

## 4. 位域

### 4.1 `R16_RTC_CTLRH`（偏移 `0x00`）— 中断使能

| 位 | 名称 | 描述 |
|----|------|------|
| `[15:3]` | Reserved | — |
| 2 | **`OWIE`** | 溢出中断使能 |
| 1 | **`ALRIE`** | 闹钟中断使能 |
| 0 | **`SECIE`** | 秒中断使能 |

### 4.2 `R16_RTC_CTLRL`（偏移 `0x04`）— 状态/控制

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[15:6]` | Reserved | RO | — | 0 |
| 5 | **`RTOFF`** | RO | 最近一次写 RTC 已完成；`1`=可写；`0`=仍在进行 | 1 |
| 4 | **`CNF`** | RW | **配置模式**：`1`=进入，允许写 `CNT/ALR/PSCR`；`0`=退出开始更新 | 0 |
| 3 | **`RSF`** | RW0 | 寄存器同步标志；读 `CNT/ALR/PSCR` 前须等硬件置位；PB1 复位/时钟停后软件应先清 | 0 |
| 2 | **`OWF`**  | RW0 | 32 位计数器溢出；只能软件清 | 0 |
| 1 | **`ALRF`** | RW0 | 闹钟事件（`CNT==ALR`）；只能软件清 | 0 |
| 0 | **`SECF`** | RW0 | 秒事件（预分频下降沿），计数器自增 1；只能软件清 | 0 |

### 4.3 `R16_RTC_PSCRH` / `PSCRL`（偏移 `0x08`/`0x0C`）— 预分频重装

- `PSCRH[3:0]`=`PRL[19:16]`、`PSCRL[15:0]`=`PRL[15:0]`，**WO**；
- **实际分频因子 = `PRL[19:0] + 1`**；
- 例：LSE = 32768 Hz → `PRL = 0x7FFF` → 1 Hz `TR_CLK`（秒事件）。

### 4.4 `R16_RTC_DIVH` / `DIVL`（偏移 `0x10`/`0x14`）— 当前分频计数

- `DIV` 为**自减计数器**：每个 `RTC_CLK` -1，溢出时输出 `TR_CLK` 并从 `PRL` 重装；
- **只读**：读到的是瞬时剩余值（用于**亚秒精度**时间戳）。

### 4.5 `R16_RTC_CNTH` / `CNTL`（偏移 `0x18`/`0x1C`）— 计数器

- `CNT[31:0]` 由 `TR_CLK` 触发自增（一般 1 秒/次）；
- 写入需**配置模式**。

### 4.6 `R16_RTC_ALRMH` / `ALRML`（偏移 `0x20`/`0x24`）— 闹钟

- `ALR[31:0]`==`CNT[31:0]` 时产生闹钟事件（`ALRF=1`）；
- 写入需**配置模式**。

## 5. RTC 的 ALARM 也能唤醒 EXTI17 / PWR

- **`EXTI17`** 映射 **RTC 闹钟事件**，可用于从 **停机 / 待机** 唤醒（见 [09-EXTI-PFIC-STK-寄存器位域详述.md](./09-EXTI-PFIC-STK-寄存器位域详述.md)）；
- 与 **PWR** 的 `EWUP / WKUP` 引脚唤醒互补，详见 [02-PWR-寄存器位域详述.md](./02-PWR-寄存器位域详述.md)。
