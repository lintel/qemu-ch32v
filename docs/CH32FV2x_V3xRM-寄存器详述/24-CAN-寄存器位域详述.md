# CAN1 / CAN2 寄存器位域详述

**来源**：《CH32FV2x_V3xRM》**第 24 章**；表 **24-1～24-4** 为 **过滤器 4 种模式矩阵**（32 位屏蔽 / 32 位列表 / 16 位屏蔽 / 16 位列表）；表 **24-5 / 24-6** 为 **CAN1/CAN2 主控/状态/位时序**；**24-7 / 24-8** 为 **CAN1/CAN2 邮箱**；**24-9** 为 **过滤器（CAN1/CAN2 共用）**。  
**原文**：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)（V2.4 自 **约 PDF 第 363 页** 起，寄存器至 **p370+** 续表）。  
**头文件**：`CAN_TypeDef` 含 `CTLR` 至 `FWR` 及 **3×Tx/2×Rx 邮箱、28×Filter 双寄存器**；**操作须 32 位**（手册 24.7 首段）。

> **与 USBD 共享 RAM**：`CAN` 与 **第 21 章 USBD** 共用缓冲概念易混 — **本 CAN 为独立 BxCAN 外设**；**USBD** 的 **0x40006000** 为全速 **PMA 缓冲**，勿与邮箱 RAM 混读（见各自章节）。

---

## 1. 表 24-5 / 24-6 控制/状态/位时序（R32_）

| 名称 | CAN1 | CAN2 | 说明 |
|------|------|------|------|
| 主控 | `0x40006400` | `0x40006800` | `CTLR` 初始化/睡眠/时序/发送请求等（复位 `0x00010002` 一带） |
| 状态 | `+0x04` | 同 | `STATR` |
| 发状态 | `+0x08` | 同 | `TSTATR` 三邮箱 TME 等（典型复位 `0x1C000000`） |
| 收 FIFO0/1 | `+0x0C` / `+0x10` | 同 | `RFIFO0/1` `FMP/ FULL/ FOVR/ RFOM` |
| 中断使能 | `+0x14` | 同 | `INTENR` |
| 错误/LEC | `+0x18` | 同 | `ERRSR` 与 **LEC** 编码见手册 |
| 位时序 | `+0x1C` | 同 | **`BTIMR` 仅初始化模式可改**（手册明令） |
| 时间触发 | `+0x20` / `+0x24` | 同 | `TTCTLR` / `TTCNT`（若芯片支持 TTCAN 类功能，见 24.5/24.6） |

## 2. 表 24-7 / 24-8 邮箱

**CAN1**（起始 `0x40006580`）；**CAN2**（起始 `0x40006980`）。每邮箱 4 个 32 位字，**步进 `0x10`**：

| 偏移 | 寄存器 |
|------|--------|
| `+0x00` | `TXMIRx` 发送邮箱 x 标识符 |
| `+0x04` | `TXMDTRx` 数据长度 + 时间戳 |
| `+0x08` | `TXMDLRx` 低字节数据（0..3） |
| `+0x0C` | `TXMDHRx` 高字节数据（4..7） |

- **3 个发送邮箱**：`TXMBOX0/1/2` 绝对地址 **`0x40006580 / 0x590 / 0x5A0`**（CAN2：`0x980 / 0x990 / 0x9A0`）；
- **2 个接收 FIFO 邮箱**：`RXMIR0` 起 `0x400065B0`、`RXMIR1` 起 `0x400065C0`（CAN2：`0x9B0 / 0x9C0`）；对应 `RXMDTR / RXMDLR / RXMDHR` 以 `+0x04/+0x08/+0x0C` 排列。

`CAN_TxMailBox_TypeDef` / `CAN_FIFOMailBox_TypeDef` 与上列布局同 ST BxCAN 系。

---

## 3. 表 24-9 过滤器（`0x40006600` 起，**CAN1/CAN2 共用**）

> **重要**：芯片**只有一组** 28 个过滤器组，位于 **`CAN1` 寄存器空间** `0x40006600~0x400067FF`。**CAN2 没有独立过滤器寄存器**；由 **`CAN1_FCTLR.CAN2SB[5:0]`**（偏移 `[13:8]`，复位 `01110b`=14）划分：**组号 `< CAN2SB` 归 CAN1、`≥ CAN2SB` 归 CAN2**。

**寄存器布局**：

| 名称 | 地址 | 说明 | 复位值 |
|------|------|------|--------|
| `R32_CAN1_FCTLR` | `0x40006600` | 过滤器主控制（`CAN2SB[13:8]`、`FINIT`） | `0x2A1C0E01` |
| `R32_CAN1_FMCFGR` | `0x40006604` | 过滤器模式（每位：0=屏蔽 / 1=列表） | `0x00000000` |
| `R32_CAN1_FSCFGR` | `0x4000660C` | 过滤器位宽（0=16 位 / 1=32 位） | `0x00000000` |
| `R32_CAN1_FAFIFOR` | `0x40006614` | FIFO 分配（0=FIFO0 / 1=FIFO1） | `0x00000000` |
| `R32_CAN1_FWR` | `0x4000661C` | 过滤器激活（每组 1 位） | `0x00000000` |
| `R32_CAN1_F0R1..F27R1` | `0x40006640 + 8*n` | 过滤器组 n 寄存器 1 | `X` |
| `R32_CAN1_F0R2..F27R2` | `0x40006644 + 8*n` | 过滤器组 n 寄存器 2 | `X` |

- `FCTLR`/`FMCFGR`/`FSCFGR`/`FAFIFOR`/`FWR` 之间有 **4 字节保留孔**（`0x08/0x10/0x18`）；
- `FxR1/FxR2` **成对 +8 字节步进**，从 `F0R1 @ 0x40006640` 至 `F27R2 @ 0x400066FC`。
