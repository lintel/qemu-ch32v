## 1. 原理

**TKEY 与 ADC 共用同一套硬件**：TKEY1 复用 **ADC1**（基址 `0x40012400`）、TKEY2 复用 **ADC2**（基址 `0x40012800`）。所有 TKEY 寄存器**映射到 ADC 对应偏移**，配置 ADC 时解释为"采样时间 / 规则数据"；配置 TKEY 时则解释为"充电时间 / 启动放电 / 采集数据"。

典型流程：
1. 使能 ADC 时钟（`RCC_APB2PCENR.ADC1EN/ADC2EN=1`）、配置对应 GPIO 为**模拟输入**；
2. 在 `ADC_CTLR1.TKENABLE` 置位开启 TKEY 模式（见 ADC 章，bit 24）；
3. 为每个通道设 `CHARGE1/2` 中的 `TKCGx[2:0]` 充电周期（时基=ADC 时钟）；
4. 设 `CHGOFFSET.TKCGOFFSET[7:0]` 总充电时间偏移；
5. 写 `ACT_DCG.TKACT_DCG[7:0]` 启动一次通道检测，同时配置**放电时间**；
6. 从 `DR.DATA[15:0]` 读回转换结果。

## 2. 表 13-1 / 13-2 寄存器（映射到 ADC1/ADC2 空间）

### 2.1 TKEY1（ADC1，基 `0x40012400`）

| 名称 | 地址 | 偏移 | 映射的 ADC1 寄存器 |
|------|------|------|---------------------|
| `R32_TKEY1_CHARGE1`   | `0x4001240C` | `+0x0C` | `ADC1_SAMPTR1` |
| `R32_TKEY1_CHARGE2`   | `0x40012410` | `+0x10` | `ADC1_SAMPTR2` |
| `R32_TKEY1_CHGOFFSET` | `0x4001243C` | `+0x3C` | `ADC1_IDATAR1`（**写**为 TKEY 偏移，**读**为注入数据） |
| `R32_TKEY1_ACT_DCG`   | `0x4001244C` | `+0x4C` | `ADC1_RDATAR`（**写**） |
| `R32_TKEY1_DR`        | `0x4001244C` | `+0x4C` | `ADC1_RDATAR`（**读**） |

### 2.2 TKEY2（ADC2，基 `0x40012800`）

| 名称 | 地址 | 偏移 | 映射的 ADC2 寄存器 |
|------|------|------|---------------------|
| `R32_TKEY2_CHARGE1`   | `0x4001280C` | `+0x0C` | `ADC2_SAMPTR1` |
| `R32_TKEY2_CHARGE2`   | `0x40012810` | `+0x10` | `ADC2_SAMPTR2` |
| `R32_TKEY2_CHGOFFSET` | `0x4001283C` | `+0x3C` | `ADC2_IDATAR1` |
| `R32_TKEY2_ACT_DCG`   | `0x4001284C` | `+0x4C` | `ADC2_RDATAR`（写） |
| `R32_TKEY2_DR`        | `0x4001284C` | `+0x4C` | `ADC2_RDATAR`（读） |

> **`ACT_DCG` 与 `DR` 共享 `0x4C`**：**写** 视为启动并设置放电时间；**读** 视为数据。

## 3. 位域

### 3.1 `TKEYx_CHARGE1`（`+0x0C`）— 通道 10..17 充电时间

| 位域 | 名称 | 说明 |
|------|------|------|
| `[31:24]` | Reserved | — |
| `[23:21]` | `TKCG17[2:0]` | 通道 17 充电时间 |
| `[20:18]` | `TKCG16[2:0]` | 通道 16 |
| `[17:15]` | `TKCG15[2:0]` | 通道 15 |
| `[14:12]` | `TKCG14[2:0]` | 通道 14 |
| `[11:9]`  | `TKCG13[2:0]` | 通道 13 |
| `[8:6]`   | `TKCG12[2:0]` | 通道 12 |
| `[5:3]`   | `TKCG11[2:0]` | 通道 11 |
| `[2:0]`   | `TKCG10[2:0]` | 通道 10 |

**3 位编码**（所有 `TKCGx`）：`000`=1.5、`001`=7.5、`010`=13.5、`011`=28.5、`100`=41.5、`101`=55.5、`110`=71.5、`111`=239.5 ADC 时钟周期。

### 3.2 `TKEYx_CHARGE2`（`+0x10`）— 通道 0..9 充电时间

`[29:27]` `TKCG9` / `[26:24]` `TKCG8` / `[23:21]` `TKCG7` / `[20:18]` `TKCG6` / `[17:15]` `TKCG5` / `[14:12]` `TKCG4` / `[11:9]` `TKCG3` / `[8:6]` `TKCG2` / `[5:3]` `TKCG1` / `[2:0]` `TKCG0`；编码同上。

### 3.3 `TKEYx_CHGOFFSET`（`+0x3C`，**WO**）— 充电时间偏移

| 位域 | 名称 | 说明 |
|------|------|------|
| `[31:8]` | Reserved | — |
| `[7:0]` | `TKCGOFFSET[7:0]` | **总充电时间 = `TKCGOFFSET + TKCGx`** |

> 读此地址时表现为 `ADC_IDATAR1`（注入数据）。

### 3.4 `TKEYx_ACT_DCG`（`+0x4C`，**WO**）— 启动与放电

| 位域 | 名称 | 说明 |
|------|------|------|
| `[7:0]` | `TKACT_DCG[7:0]` | 写入**即启动一次**对应通道的 TKEY 检测，值为**放电时间** |

### 3.5 `TKEYx_DR`（`+0x4C`，**RO**）— 数据

| 位域 | 名称 | 说明 |
|------|------|------|
| `[15:0]` | `DATA[15:0]` | 转换结果（电容电荷等效数） |

## 4. 与 ADC 的关系

- **ADC 必须先初始化**（`ADON/RSTCAL/CAL`）。
- 通道切换走 `ADC_RSQRx` 规则序列（只用 `L=0` 单通道即可）。
- TKEY 模式开启后，**`ADC_IDATAR1` 会被写入破坏**，如需注入采集需自行保存。
- 详见 [12-ADC-寄存器位域详述.md](./12-ADC-寄存器位域详述.md) 的 `CTLR1.TKENABLE`、`AUX` 与采样扩展。
