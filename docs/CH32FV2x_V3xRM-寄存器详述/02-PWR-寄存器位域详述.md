# PWR（电源控制）寄存器位域详述

**来源**：《CH32F/V20x_V30x_V31x 系列应用手册》V2.4（[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)），**第 2 章「电源控制（PWR）」**（PDF 第 **p20–22**）。  
**按页导出**：[`_layout_extract/ch02-pwr_p20-35.txt`](./_layout_extract/ch02-pwr_p20-35.txt)。

## 1. 基址与表 2-2

**APB1 挂载，基址 `0x40007000`**。

| 名称 | 绝对地址 | 偏移 | 描述 | 复位值 |
|------|----------|------|------|--------|
| `R32_PWR_CTLR` | `0x40007000` | `0x00` | 电源控制 | `0x00000000` |
| `R32_PWR_CSR`  | `0x40007004` | `0x04` | 电源控制/状态 | `0x00000000` |

> **使用前** 需在 **`RCC_APB1PCENR`** 置 **`PWREN(bit28)=1`** 才能访问寄存器。

## 2. `R32_PWR_CTLR`（偏移 `0x00`）— 电源控制

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[31:21]` | Reserved | RO | — | 0 |
| 20 | **`RAMLV`** | RW | **RAM 低电压模式** 使能（进一步降功耗）。**仅 `LPDS=1` 时有效** | 0 |
| 19 | **`R30KVBAT`** | RW | **VBAT** 供电下，**Standby** 保留 **30K RAM**；`0`=不带电 / `1`=带电。**适用 D8/D8C 系（F20x_D8/D8C、V30x_D8/D8C、V31x_D8C、V20x_D8/D8W、F20x_D8）** | 0 |
| 18 | **`R2KVBAT`** | RW | 同上，对 **2K RAM**；**D6 系**此位改指 **20K RAM**（V20x_D6 / F20x_D6） | 0 |
| 17 | **`R30KSTY`** | RW | **Standby**（VDD 供电）下保留 **30K RAM**（D8/D8C 系） | 0 |
| 16 | **`R2KSTY`** | RW | **Standby** 下保留 **2K RAM**（D8/D8C 系）；**D6 系**指 **20K RAM** | 0 |
| `[15:9]` | Reserved | RO | — | 0 |
| 8  | **`DBP`** | RW | **后备域写使能**。`0`=禁止写 RTC/BKP；`1`=允许。**RTC 时钟选 HSE/128 分频时必须为 1** | 0 |
| `[7:5]` | **`PLS[2:0]`** | RW | **PVD 阈值**；**VLEVEL=1（VDD=2.4V 产品）**：`000`=2.37/2.29V、`001`=2.55/2.46V、`010`=2.63/2.55V、`011`=2.76/2.67V、`100`=2.87/2.78V、`101`=3.03/2.93V、`110`=3.18/3.06V、`111`=3.29/3.19V；**VLEVEL=0（VDD=1.8V）**：`000`=2.19/2.13V、`001`=2.33/2.25V、`010`=2.39/2.32V、`011`=2.48/2.42V、`100`=2.57/2.51V、`101`=2.69/2.61V、`110`=2.78/2.69V、`111`=2.88/2.79V（**上升沿/下降沿**） | `000b` |
| 4  | **`PVDE`** | RW | 电压监测使能 | 0 |
| 3  | **`CSBF`** | RW1 | 写 1 清 **`SBF`**（待机标志）；读为 0 | 0 |
| 2  | **`CWUF`** | RW1 | 写 1 后 **2 个系统周期** 清 **`WUF`**（唤醒标志） | 0 |
| 1  | **`PDDS`** | RW | 深睡眠模式：`0`=**停机**（由 `LPDS` 决定调节器）；`1`=**待机** | 0 |
| 0  | **`LPDS`** | RW | `PDDS=0` 时：`0`=调节器正常 / `1`=调节器低功耗 | 0 |

> **复位域注**：**`[20:16]` 五位** 仅由 **后备域复位** 清 0；其余位从待机唤醒时复位。

## 3. `R32_PWR_CSR`（偏移 `0x04`）— 电源状态

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[31:9]` | Reserved | RO | — | 0 |
| 8  | **`EWUP`** | RW | **WKUP 引脚** 使能：`1`=强制下拉输入，可从待机唤醒；`0`=作普通 GPIO | 0 |
| `[7:3]` | Reserved | RO | — | 0 |
| 2  | **`PVDO`** | RO | PVD 输出（仅 `PVDE=1` 有效）：`0`=VDD/VDDA **高于** `PLS`；`1`=**低于** | 0 |
| 1  | **`SBF`**  | RO | **待机标志**：`0`=不在待机；`1`=进入过待机。由 `CTLR.CSBF=1` 清 | 0 |
| 0  | **`WUF`**  | RO | 唤醒事件（WKUP 引脚 / RTC 闹钟）；**`CWUF=1` 清** | 0 |

> **本寄存器从待机唤醒后保持不变**。

## 4. 低功耗模式（表 2-1 摘要）

| 模式 | 进入方式 | 电压调节器 | 唤醒源 | 唤醒延迟 |
|------|----------|-----------|--------|-----------|
| **睡眠（Sleep）** | `WFI` / `WFE` | 开 | 任何中断/事件 | 即时 |
| **停机（Stop）** | `WFI`（`PDDS=0`），SCB 深睡眠 | `LPDS` 选 | EXTI/RTC 闹钟/USB 唤醒等 | 约 μs 级 |
| **待机（Standby）** | `WFI`（`PDDS=1`），SCB 深睡眠 | 关 | **WKUP 引脚**、IWDG、RTC、NRST | 约 ms 级（等 HSI） |

**进入步骤**：
1. 清 `CWUF=1` / `CSBF=1`；
2. 配 `PDDS` / `LPDS` / `EWUP`；
3. 置 **`SCB.SCR.SLEEPDEEP=1`**（停机/待机）；
4. `WFI` 或 `WFE`。

---

## 5. 与 RCC / VBAT

- **`RCC_BDCTLR`** 的 `LSEON/LSEBYP/RTCEN/RTCSEL` 等均位于 **后备域**，**必须** 先 `DBP=1` 才能写。
- **后备域复位**：由 `RCC_BDCTLR.BDRST=1` 触发，会清 `PWR_CTLR[20:16]`。
- 详见 [03-RCC-寄存器位域详述.md](./03-RCC-寄存器位域详述.md) 第 9/10 节。
