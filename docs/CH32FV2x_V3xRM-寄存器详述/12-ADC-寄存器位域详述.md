# ADC1 / ADC2 寄存器位域详述

**来源**：《CH32FV2x_V3xRM》**第 12 章**；表 **12-5**、**12-6** 及 **12.3.x** 各节。  
**原文**：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)（V2.4 时 ADC 章约 **PDF 第 157–179 页**；寄存器从 **p166** 起）。  
**头文件**（布局参考）：`reference-project/ch32fun/.../ch32v30xhw.h` 中 `ADC_TypeDef` 与下表**偏移一致**，但**未包含** `ADCx_AUX`（`+0x54`），若需 AUX/扩展采样配置请按手册或自行扩展结构体。

---

## 1. 适用与说明

- 本章适用于 **CH32F20x、CH32V20x、CH32V30x、CH32V31x** 中具备双 ADC 的型号；**仅 ADC1** 具备 `TSVREFE`（内部温度/参考）及双 ADC 主控相关行为（如 DMA），详见手册 **12.2** 与 **ADC1_CTLR1`DUALMOD`**。
- **ADC 时钟分频** 在 RCC（**第 3 章**，`ADCPRE`）配置，可交叉参考 [03-RCC-寄存器位域详述.md](./03-RCC-寄存器位域详述.md)。
- `ADC1_AUX` / `SAMPTR` 中 **SMPx 双套编码**、**PGA/BUFEN/TKEY** 等，手册注明仅部分 **D8 / D8C 批号** 有效，**以数据手册 + PDF 原文为准**。

## 2. 基址与表 12-5 / 12-6 全表（R32_ 名）

### 2.1 ADC1（表 12-5）

| R32_ 名 | 访问地址 | 描述 | 典型复位值 |
|---------|----------|------|------------|
| `R32_ADC1_STATR` | `0x40012400` | 状态 | `0x00000000` |
| `R32_ADC1_CTLR1` | `0x40012404` | 控制 1 | `0x00000000` |
| `R32_ADC1_CTLR2` | `0x40012408` | 控制 2 | `0x00000000` |
| `R32_ADC1_SAMPTR1` | `0x4001240C` | 采样时间 1（通道 10–17 等，见手册位图） | `0x00000000` |
| `R32_ADC1_SAMPTR2` | `0x40012410` | 采样时间 2（通道 0–9） | `0x00000000` |
| `R32_ADC1_IOFR1`～`R32_ADC1_IOFR4` | `0x40012414`～`0x40012420` | 注入数据偏移 1–4 | `0x00000000` |
| `R32_ADC1_WDHTR` | `0x40012424` | 看门狗高阈值 | `0x00000FFF` |
| `R32_ADC1_WDLTR` | `0x40012428` | 看门狗低阈值 | `0x00000000` |
| `R32_ADC1_RSQR1`～`R32_ADC1_RSQR3` | `0x4001242C`～`0x40012434` | 规则序列 | `0x00000000` |
| `R32_ADC1_ISQR` | `0x40012438` | 注入序列 | `0x00000000` |
| `R32_ADC1_IDATAR1`～`R32_ADC1_IDATAR4` | `0x4001243C`～`0x40012448` | 注入数据 1–4 | `0x00000000` |
| `R32_ADC1_RDATAR` | `0x4001244C` | 规则数据；双 ADC 时 **高 16 位为 ADC2 规则数据** | `0x00000000` |
| `R32_ADC1_AUX` | `0x40012454` | 采样时间扩展/通道选择（见 12.3.15，**批号限定**） | `0x00000000` |

> 相对 **ADC1 基址** `0x40012400` 的**偏移**即上表各地址低 12 位；与 `ADC_TypeDef` 成员顺序一致至 `RDATAR`；**`+0x50` 为 AUX**（`RDATAR` 后为 `+0x08` 空洞至 `+0x54`）。

### 2.2 ADC2（表 12-6）

| R32_ 名 | 访问地址 | 说明 |
|---------|----------|------|
| `R32_ADC2_*` | **`0x40012800` 起** 与 ADC1 同名寄存器一一对应 | 双 ADC 时 **ADC1** 的 `DUALMOD` 决定联动模式；**仅 ADC1** 使用 `TSVREFE`等部分位 |

`ADC2` 基址 `0x40012800`；`R32_ADC2_RDATAR` 为 `0x4001284C`，**双模式时** `R32_ADC1_RDATAR` 才承载 **DATA + ADC2DATA** 拼合。

## 3. 相对 `ADC1_BASE` 的 32 位字偏移（开发对照）

| 偏移 | 寄存器 |
|------|--------|
| `+0x00` | `STATR` |
| `+0x04` | `CTLR1` |
| `+0x08` | `CTLR2` |
| `+0x0C` | `SAMPTR1` |
| `+0x10` | `SAMPTR2` |
| `+0x14`～`+0x20` | `IOFR1`～`4` |
| `+0x24` / `+0x28` | `WDHTR` / `WDLTR` |
| `+0x2C`～`+0x34` | `RSQR1`～`3` |
| `+0x38` | `ISQR` |
| `+0x3C`～`+0x48` | `IDATAR1`～`4` |
| `+0x4C` | `RDATAR` |
| `+0x50` | *保留（手册未在表 12-5 中命名字）* |
| `+0x54` | `AUX`（手册表 12-5） |

## 4. 关键位域（节选）

### 4.1 `STATR`（`0x00`）

| 位 | 名 | 访问 | 说明 |
|----|-----|------|------|
| 4 | **STRT** | RW0 | 规则转换已开始 |
| 3 | **JSTRT** | RW0 | 注入转换已开始 |
| 2 | **JEOC** | RW0 | 注入组结束 |
| 1 | **EOC** | RW0 | 转换结束；读 `RDATAR` 可清除（见手册） |
| 0 | **AWD** | RW0 | 模拟看门狗事件 |

### 4.2 `CTLR1`（`0x04`）

- **[28:27] PGA[1:0]**：增益 ×1/×4/×16/×64（与 BUFEN 等联用，见原文）。  
- **26 BUFEN、25 TKITUNE、24 TKENABLE**：Buffer / 触摸 TKEY 相关。  
- **23/22 AWDEN / JAWDEN**：看门狗使能。  
- **[19:16] DUALMOD[3:0]**：双 ADC 模式；**ADC2 中保留**。  
- **[15:13] DISCNUM、[12] JDISCEN、[11] DISCEN、[10] JAUTO、[9] AWDSGL、[8] SCAN**：扫描与间断。  
- **[7] JEOCIE、[6] AWDIE、[5] EOCIE、[4:0] AWDCH[4:0]**：中断与 AWD 通道号。

### 4.3 `CTLR2`（`0x08`）

| 位 | 名 | 说明 |
|----|-----|------|
| 23 | **TSVREFE** | 温度与 Vrefint 通道；**仅 ADC1** |
| 22 / 21 | **SWSTART** / **JSWSTART** | 软件启动规则/注入 |
| 20 / 19:17 | **EXTTRIG** / **EXTSEL[2:0]** | 外部触发规则（定时器/EXTI/SW） |
| 15 / 14:12 | **JEXTTRIG** / **JEXTSEL[2:0]** | 注入外部触发 |
| 11 | **ALIGN** | 0 右对齐，1 左对齐 |
| 8 | **DMA** | **仅 ADC1** 使用 DMA 时应置位等（见 12.2 说明） |
| 3 / 2 / 1 / 0 | **RSTCAL** / **CAL** / **CONT** / **ADON** | 校准、连续、开关 |

**EXTSEL / JEXTSEL** 各触发源编码见手册 **表 12-1、12-2**（定时器 CCR/TRGO/EXTI 等）。

### 4.4 `SAMPTR1` / `SAMPTR2`

- 每通道 **3 位 SMPx**，标准 **000～111** 对应 **1.5～239.5** 个 ADC 时钟周期；部分型号在 **SMP=100～111** 时配合 **`ADC1_AUX[17:0]` 的 `ADC_SMP_SELx`** 使用 **2.5～5.5T** 短周期（**批号限定**）。

### 4.5 `RSQR1` / `2` / `3`、`ISQR`

- 规则 **L[3:0]+1** 为序列长度 1–16；**SQn[4:0]** 为通道 0–17。  
- 注入 **JL[1:0]+1** 定长度；**JSQ1…4** 顺序**随 JL 变化**（**非**总是从 JSQ1 起），手册 **12.3.12** 有示例。

### 4.6 `RDATAR`（`0x4C`）

- **[31:16] ADC2DATA**：**仅在 ADC1** 且双 ADC 读规则数据时有效；**ADC2 的 RDATAR 中该域不用**。  
- **[15:0] DATA**：本 ADC 规则数据。

### 4.7 `AUX`（`0x54`）

- **[17:0] `ADC_SMP_SELx`**：与扩展采样周期二选一逻辑见 **12.3.15** 注。  
- **仅部分批号芯片有效**；若芯片无此功能，**勿依赖** `AUX`。

## 5. 与触摸 TKEY 的关系

第 **13 章 TKEY** 与 ADC/通道共用；手册要求 **TKEY/TSVREFE** 与 **Buffer/校准** 的先后顺序，见 **12.2**、**CTLR1** 注与 **第 13 章**。
