# DMA1 / DMA2 寄存器位域详述

**来源**：《CH32FV2x_V3xRM》**第 11 章**；表 **11-7**、**11-8** 与 **11.3.x**。  
**原文**：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)（V2.4 约 **PDF 第 139–156 页**）。  
**外设请求映像**：表 **11-2**～**11-6**、图 **11-3**、**11-4**（同章前半）。

---

## 1. 全局基址与表 11-7 / 11-8

| 控制器 | `INTFR` / `INTFCR` 基址 | 说明 |
|--------|-------------------------|------|
| **DMA1** | `0x40020000` / `0x40020004` | 通道 1–8，每通道 `CFGR, CNTR, PADDR, MADDR` 步进见下 |
| **DMA2** | `0x40020400` / `0x40020404` | 通道 1–11 + **扩展** `EXTEM_INTFR` / `EXTEM_INTFCR` 于 `0x400204D0` / `0xD4` |

**DMA1 通道 n 四寄存器首址规律**（`n=1..8`；手册表 11-7 全列）：

- 手册节 **11.3.3** 写为 **`+ (x-1)*20`** 时，**20 为十进制**，即 **`+0x14` 字节/通道**（`CFGR`→`CNTR`→`PADDR`→`MADDR` 共 16 字节，随后 **4 字节孔** 再进下一 `CFGR`）— **以 PDF 表 11-7 每行地址为准**。
- `R32_DMA1_CFGRn`：首址 `0x40020008 + (n-1)*0x14`。
- 同通道：`CNTR` 在 `CFGR+4`，`PADDR+4`，`MADDR+4`。

**手册已给出的成对关系示例**（摘录）：

- 通道 1：`CFGR1 0x40020008`，`CNTR1 0x0C`，`PADDR1 0x10`，`MADDR1 0x14`  
- 通道 2：`0x1C` 起下一组，依此类推至通道 8：`CFGR8 0x40020094` … `MADDR8 0x400200A0`。

**DMA2** 通道 1–8 在 `0x40020408` 起**同样 +0x14 分通道布局**；**通道 9–11** 继续至 `0xB0` 段；**`R32_DMA2_EXTEM_INTFR/INTFCR`** 在 **`0x400204D0` / `0xD4`**（大容量/部分型号，见手册注与 **V20x_D6/D8** 等说明）。

## 2. 通道配置 `DMAy_CFGRx`（**11.3.3**）

| 位 | 名 | 说明 |
|----|-----|------|
| 14 | **MEM2MEM** | 存储器到存储器 |
| [13:12] | **PL[1:0]** | 通道优先级 低/中/高/最高 |
| [11:10] | **MSIZE[1:0]** | 存宽 8/16/32 |
| [9:8] | **PSIZE[1:0]** | 外设宽 8/16/32 |
| 7 | **MINC** | 存储器地址递增 |
| 6 | **PINC** | 外设地址递增 |
| 5 | **CIRC** | 循环模式 |
| 4 | **DIR** | 0=读外设到存；1=读存写外设 |
| 3 | **TEIE** / 2 **HTIE** / 1 **TCIE** | 错/半完/全完中断使能 |
| 0 | **EN** | 使能；传输出错时硬件可清 0 |

---

## 3. `DMAx_INTFR` / `DMAx_INTFCR`

- **每通道 4 标志位**：`TEIFx`（传输出错）、`HTIFx`（半传输）、`TCIFx`（传完）、`GIFx`（前三种 OR）。  
- **写 `INTFCR` 的 CTEIF/CHTIF/CTCIF/CGIF 对应位** 为 **清除** 操作。  
- **通道 8** 标志位/清除位在部分型号上有效（**手册 11.3.1/11.3.2 注**）。

---

## 4. `CNTR` / `PADDR` / `MADDR`

- **`CNTR`**：剩余传输**次数**；为 0 时通道不起传；使能时由硬件递减。  
- 地址寄存器在 **8/16/32 位** 与 `MINC`/`PINC` 下行为见表 **11-1** 及 **11.1** 小数据宽度说明。

---

## 5. 与头文件

`ch32v30xhw.h` 中 `DMA_TypeDef`（`INTFR`+`INTFCR`）与 `DMA_Channel_TypeDef`（`CFGR, CNTR, PADDR, MADDR`）与上表**同一逻辑**；多通道通过**指针数组**或**基址+0x20×(n-1)** 等访问（**以你使用的 SPL 变体**为准）。
