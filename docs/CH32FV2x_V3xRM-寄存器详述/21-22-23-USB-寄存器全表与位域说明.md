# USB（USBD / USBHS / USBFS+OTG）寄存器全表与位域说明

**来源**：《CH32FV2x_V3xRM》**第 21 章**（USBD）、**第 22 章**（USBHS）、**第 23 章**（USBFS/OTG_FS 设备与主机）。  
**原文**：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)（V2.4 约 **PDF 第 313–331 / 328–346 / 347–362+** 页，主机寄存器在 **p355+** 仍属第 23 章）。  
**专题展开**（GPIO 上拉、RCC、常用编程顺序）：[`../CH32V30X/CH32V307-USB-Regs.md`](../CH32V30X/CH32V307-USB-Regs.md)  
**本页**：按手册**表 21-5～21-7、22-1/22-2/22-3、23-1/23-3/23-5** 汇总**地址 + 位域入口**；**USBD** 另见 **§1.5～1.8** 位域；**USBHS 主机**见 **§2.3**。**请以 PDF 为准**。

> **USBD 与 CAN** 共享 **0x40006000** 起 **512B SRAM** 做包缓冲，不可与 CAN 同时无规划占用（**第 21 章**首段说明）。  
> **头文件** `ch32v30xhw.h`：`USBD_TypeDef` 在 **`USBD_BASE = 0x40005C00`**，`EPR[0..7]` 与 `CNTR/ISTR/...` 的偏移与 **表 21-5/6 绝对地址**一致（`CNTR` 在 `+0x40` → `0x40005C40`）；`USBHSD`/`USBFS` 与手册 **R8_/R32_** 名一致。

## 1. 第 21 章 — USBD（全速设备，与 STM32 USB 全速外设同族）

### 1.1 基址（节 21.3）

- **端点/状态类**：`0x40005C00` 起 `EPR0`～`EPR7`（表 21-6）  
- **控制/中断类**：`0x40005C40` 起 `CNTR/ISTR/FNR/DADDR/BTABLE`（表 21-5，表中写「通用类 0x40005C40」为 **CNTR** 在 **基址+0x40**）  
- **分组缓冲描述**（BDT）：**`0x40006000 + BTABLE` 起**，与 **端点 0..7 一一对应** 的 Tx/Rx **ADDR/COUNT**（表 21-7）

### 1.2 表 21-5 — USBD 通用类

| 名称 | 地址 | 描述 | 典型复位值 |
|------|------|------|------------|
| `R16_USBD_CNTR` | `0x40005C40` | 控制、中断使能、掉电/强制复位等 | `0x0003`（手册印值；以芯片为准） |
| `R16_USBD_ISTR` | `0x40005C44` | 中断状态、CTR/端点/方向等 | `0x0000` |
| `R16_USBD_FNR` | `0x40005C48` | 帧号、**RXDP/RXDM/LSOF/LOCK** 等 | `0x0XXX` |
| `R16_USBD_DADDR` | `0x40005C4C` | 设备地址 **ADD[6:0]**、**EF** 使能 | `0x0000` |
| `R16_USBD_BTABLE` | `0x40005C50` | 缓冲描述表在 **PMA 内**偏移（×2 等规则见 21.3 注与图） | `0x0000` |

`CNTR` 位：手册 **图 21.x / 21.3.1** 含 **CTRM, PMAOVRM, ERRM, WKUPM, SUSPM, RSTM, SOFM, ESOFM, …, RESUME, FSUSP, PDWN, FRES** 等（与 `ch32v30xhw.h` 中 `USBD_*` 宏一致）。  
`EPRx` 位：手册 **15 CTR_RX, 14 DTOG_RX, [12:11] STAT_RX, 10 SETUP, [9:8] EPTYPE, 8 EPKIND, 7 CTR_TX, 6 DTOG_TX, [4:3] STAT_TX, [3:0] EA** 类布局（**与宏 `USBD_CTR_RX` 等**一致）。  
`COUNTx_RX`：**BLSIZE, NUM_BLOCK, 实际计数字段** 见 21.3.7/表注。

### 1.3 表 21-6 — 端点类

`R16_USBD_EPR0`～`R16_USBD_EPR7`：`0x40005C00`～`0x40005C1C`（步进 `+0x04`）。

### 1.4 表 21-7 — 缓冲区描述（相对于 `0x40006000+[USBD_BTABLE]`）

每端点 **4 个 32 位字**（`R16_USBD_ADDRx_TX`/`COUNTx_TX`/`ADDRx_RX`/`COUNTx_RX`，**各占 32 位对齐槽**）；相邻端点 **步进 `0x10`（16 字节）/端点**。例如（`USBD_BTABLE=0`）：

- EP0：`ADDR0_TX @ +0x00`、`COUNT0_TX @ +0x04`、`ADDR0_RX @ +0x08`、`COUNT0_RX @ +0x0C`
- EP1：`ADDR1_TX @ +0x10`、…、`COUNT1_RX @ +0x1C`
- EPn：**起始 = `+0x10 * n`**，同构展开到 **EP7**。

**实际硬件寄存器均为 16 位**，但**在此 BDT 存储里每 16 位占一个 32 位槽**（低 16 位有效）；手册表 21-7 每行地址步进 `+0x04`，即 **32 字节编码一个端点的 4 项** 并非手册原意，**步进为 16 字节/端点**。

### 1.5 `R16_USBD_CNTR` 位域（**21.3.1**）

- **[15:8] 中断使能**：`CTRM, PMAOVRM, ERRM, WKUPM, SUSPM, RSTM, SOFM, ESOFM`（CTR/溢出/错/唤醒/挂起/复位/SOF/ESOF）。  
- **bit7** `MODE_1WIRE`：单线模式（**部分批号/型号**限定，见手册注）。  
- **bit4** `RESUME`：远程唤醒时输出唤醒序列（**FSUSP=1 时**才可置位）。  
- **bit3** `FSUSP`：屏蔽挂起检测（挂起后软件常置位避免重复进中断）。  
- **bit2** `LPMODE`：低功耗。  
- **bit1** `PDWN`：掉电。  
- **bit0** `FRES`：**置 1 为模块强制复位**；清 0 后退出（与上电初始化、表 21-1 流程一致）。

### 1.6 `R16_USBD_ISTR` 位域（**21.3.2**）

- **[15:8]** 与 `CNTR` 使能位对应的**只读/写 0 清**标志：`CTR, PMAOVR, ERR, WKUP, SUSP, RST, SOF, ESOF`。  
- **bit4** `DIR`：本次 CTR 关联 **IN(0) 与 OUT/SETUP(1)**（与 `CTR_TX` / `CTR_RX` 同现时的优先级以手册说明为准）。  
- **[3:0]** `EP_ID`：发生 CTR 的端点号（多路挂起时硬件按**同步/双缓冲 > 同优先级时小号优先** 仲裁）。

### 1.7 `FNR` / `DADDR` / `BTABLE`（**21.3.3～21.3.5**）

- **`FNR`**：bit15/14 为 **RXDP/RXDM** 电平；**LCK**（SOF 已锁定后停帧计）；**LSOF[1:0]** 丢失 SOF 计数；**FN[10:0]** 当前帧号。  
- **`DADDR`**：bit7 **`EF` 为设备功能总开关**；**ADD[6:0]** 枚举分配地址。  
- **`BTABLE`**：**BTABLE[15:3]** 为 BDT 在 **`0x40006000` 空间内** 的 8 字节对齐基址（与 **表 21-7 绝对行** 一致，实际偏移为 `+BTABLE`）。

### 1.8 `R16_USBD_EPR0`～`EPR7`（**21.3.6**）

手册逐位域：**`CTR_RX`（RW0 清）**、**`DTOG_RX`（写 1 切同步）**、**`STAT_RX[1:0]`** 接收端点状态、**`SETUP`（RO）** 本次为 SETUP、**`EPTYPE[1:0]`**、**`EP_KIND`**、**`CTR_TX`（RW0）**、**`DTOG_TX`（写 1）**、**`STAT_TX[1:0]`**、**`EA[3:0]`** 端点号。**双缓冲/同步** 与 `STAT_*`、`DTOG_*` 的配合见 21.3.6 正文。

## 2. 第 22 章 — USBHS（高速/全速/低速 主机+设备，基址 `0x40023400`）

### 2.1 表 22-1 — 全局寄存器

| 名称 | 地址 | 说明 |
|------|------|------|
| `R8_USB_CTRL` | `0x40023400` | **主机/设备**、速度、**DMA/复位/FIFO 清/上拉**等 |
| `R8_USB_INT_EN` | `0x40023402` | 各事件中断使能（NAK、ISO、SETUP、FIFO 溢出、SOF、SUSP、TRANS、DET 等） |
| `R8_USB_DEV_AD` | `0x40023403` | 设备地址 |
| `R16_USB_FRAME_NO` | `0x40023404` | 帧号 |
| `R8_USB_SUSPEND` | `0x40023406` | 挂起/唤醒等 |
| `R8_USB_SPPED_TYPE` / `R8_USB_MIS_ST` / `R8_USB_INT_FG` / `R8_USB_INT_ST` / `R16_USB_RX_LEN` | `0x40023408`～`0x4002340C` | 速度类型、杂项、中断标志/状态、**本次接收长度**（手册拼写 SPPED 为原文） |

`R8_USB_CTRL` 位域（**22.2.1.1 节选**）：**7 RB_UC_HOST_MODE**，**[6:5] RB_UC_SPEED_TYPE（FS/HS/LS）**，**4 DEV_PU_EN**，**3 INT_BUSY**，**2 RST_SIE**，**1 CLR_ALL**，**0 DMA_EN** — 其余位/保留位以 PDF 为准。

### 2.2 表 22-2 — 设备模式（至端点 15，DMA+长度+双缓冲位）

- **0x40023410** `R32_UEP_CONFIG`：[31:17] 收使能；[15:1] 发使能（0 号端点常开）。  
- **0x40023414** `R32_UEP_TYPE`：同传/全双工 IN/OUT 是否 **ISO 类型**位图。  
- **0x40023418** `R32_UEP_BUF_MOD` + **高半字** `RB_UEP_ISO_BUF_MOD`：双缓冲/同步时 **SOF 时硬件切换** 说明见 22.2.2.3 与**表 21-3/端点 n 双缓冲**交叉引用。  
- **0x4002341C** `R32_UEP0_DMA`；**0x40023420`～0x40023458`** 为 **UEP1..15 收 DMA 基址**；**0x4002345C`～0x40023494`** 为 **1..15 发 DMA 基址**。  
- **0x40023498`～0x400234D4`** `R16_UEP0`～`15` `_MAX_LEN`。  
- 自 **0x400234D8** 起交错 **`R16_UEPn_T_LEN` / `R8_UEPn_TX_CTRL` / `R8_UEPn_RX_CTRL`** 至端点 15，末址 **0x40023517** 一带（**见 PDF 全表 22-2 续页**）。

`TX_CTRL` / `RX_CTRL` 中 **TOG/ACK/NAK/STALL/自动 TOG** 等位在 **22.2.2.x** 逐位说明（**22.2.2.10** 为端点发送/接收控制，命名与全速 B 类栈常用宏 `RB_UEP_*` 一致）。

### 2.3 主机模式 — **表 22-3** 全表与位域（**22.2.3**）

主机模式下 **`R8_USB_CTRL` 置 `RB_UC_HOST_MODE=1`**，与下表**复用**设备侧部分地址空间为 **单端点** 主控视图（**RX/TX 各一逻辑端点**）：

| 名称 | 地址 | 描述 | 典型复位值 |
|------|------|------|------------|
| `R8_UHOST_CTRL` | `0x40023401` | 主机口 **SOF 自动**、**PHY 挂起**、远程唤醒、发 **Resume/Suspend/总线复位** 等 | `0x00` |
| `R32_UH_CONFIG` | `0x40023410` | 位 **18** `RB_UH_EP_RX_EN` 收；位 **3** `RB_UH_EP_TX_EN` 发 | `0` |
| `R32_UH_EP_TYPE` | `0x40023414` | 位 **18** 收/位 **3** 发 是否 **同步（ISO）** | `0` |
| `R32_UH_RX_DMA` | `0x40023424` | 主机 **IN** 数据缓冲，**[16:0] 低 2 位固定 0** | `X` |
| `R32_UH_TX_DMA` | `0x40023464` | 主机 **OUT/SETUP** 数据缓冲，**[16:0] 无 4 字节对齐**要求 | `X` |
| `R16_UH_RX_MAX_LEN` | `0x400234A0` | 收包最大长 **[10:0]**，超长丢弃 | `X` |
| `R8_UH_EP_PID` | `0x400234E0` | **[7:4]** 本次事务 **TOKEN PID**；**[3:0]** 目标**端点号** | `0` |
| `R8_UH_RX_CTRL` | `0x400234E3` | **6** 不期待 IN 数据；**5** `RB_UH_R_AUTO_TOG`；**[4:3]** 期望 `DATA0/1/2/MDATA`；**2** 无 ACK；**[1:0]** 应答/NAK/… | `0` |
| `R16_UH_TX_LEN` | `0x400234E4` | 待发送有效字节 **[10:0]** | `X` |
| `R8_UH_TX_CTRL` | `0x400234E6` | **6** 不发数据（PING/SPLIT 等）；**5** `RB_UH_T_AUTO_TOG`；**[4:3]** 发送 `DATA*`**；2/1:0 期望应答/NAK/… 与手册表 **22.2.3.8～22.2.3.10** 一致 | `0` |
| `R16_UH_SPLIT_DATA` | `0x400234E8` | 高速 HUB 下 **SPLIT** 低 12 位 | `0x0XXX` |

- **`R8_UHOST_CTRL`**：bit7 `RB_UH_SOF_EN` 自动发 SOF（**断连时硬件清 0**）；**远程唤醒/Resume/Suspend/10ms 复位** 的时序见 **22.2.3.1** 注。  
- **全局**：主机仍使用与 **2.1** 相同的 `R8_USB_INT_EN` / `R16_USB_RX_LEN` 等，与设备模式分时配置。

### 2.4 与第 23 章 USBFS 的对应

**USBFS** 的全局/端点/主机表（**表 23-1、23-3、23-5**）与 USBHS **语义同构**，基址在 **`0x50000000`**，OTG 有 **`R32_USB_OTG_CR/SR`**，主机物理口 **`R8_UHOST_CTRL@0x50000001`** 见 **3.3** 与 [`CH32V307-USB-Regs`](../CH32V30X/CH32V307-USB-Regs.md) 中差异说明。

## 3. 第 23 章 — USBFS/OTG_FS（`0x50000000`）

### 3.1 表 23-1 — 基址上全局寄存器

| 名称 | 地址 | 说明 |
|------|------|------|
| `R8_USB_CTRL` 等 | `0x50000000` 起与 USBHS 命名**同类**但 **地址在 AHB/OTG 区** | 全速/OTG 全局控制、中断、帧/长度等 |
| `R32_USB_OTG_CR` / `R32_USB_OTG_SR` | `0x50000054` / `0x50000058` | OTG 角色、ID/VBUS/切换等 |

`R8_UDEV_CTRL`（`0x50000001`）为 **设备物理口** 上拉/模式；与 **EXTEN/ RCC** 组合见专题文档与 **表 23-2** 系统控制组合说明。

### 3.2 表 23-3 — 设备：端点 MOD / DMA / T_LEN / x_CTRL

- **0x5000000C`～0x0F`**：`UEP4_1_MOD`、`UEP2_3_MOD`、`UEP5_6_MOD`、`UEP7_MOD` 等。  
- **0x50000010`～0x5000002C`**：UEP0`～7` 的 `DMA`（**部分端点号在括号内与高速端点 8–15 映射**见手册表注）。  
- **0x50000030`～0x5000004F`**：各端点 **T_LEN, TX_CTRL, RX_CTRL**（与 USBHS 类似但地址布局不同）。  
- **PDF p354 上 `R8_UEP3_TX_CTRL` 等行有排版换行/地址** — **以 PDF 矢量表为准**；对勘时可参考 `_layout_extract/ch23-usbfs_*.txt` 或**放大 PDF 表**。

> **勘误注意**：`pdftotext` 在个别行将 **`0x5000003A`** 等地址断行错列，编程以 **`../CH32FV2x_V3xRM.PDF`** 中 **表 23-3** 为准。

### 3.3 表 23-5 — 主机（USB 主机全速，与 23-2 后文衔接）

| 名称 | 地址 | 说明 |
|------|------|------|
| `R8_UHOST_CTRL` | `0x50000001` | 主机口使能/复位/低速/下拉/**D+/D- 引脚只读**等（节 23.2.3.1） |
| `R32_UH_EP_MOD` | `0x5000000D` | 主机收发与 **双 64B 缓冲** 模式位 |
| `R16_UH_RX_DMA` / `R16_UH_TX_DMA` | `0x50000018` / `0x5000001C` | 主机收/发缓冲 **4 字节对齐 15:0 有效** |
| `R16_UH_SETUP` / `R8_UH_EP_PID` / `R8_UH_RX_CTRL` / `R16_UH_TX_LEN` / `R8_UH_TX_CTRL` | `0x36` / `0x38` / `0x3B` / `0x3C` / `0x3E` 一带 | 令牌/同步位/自动 TOG/SETUP 辅助 等（见 **23.2.3**） |

**表 23-6 / 23-7** 为 **发送/收双缓冲** 与 **Tx_en/Tbuf_mod / Rx_en/Rbuf_mod** 真值表。

## 4. 与 QEMU / 头文件 的提示

- **QEMU 模型**常实现 **表 22/23** 的 `R8_/R32_` 可编程视图；**USBD（第 21 章）BDT** 在另一地址空间，软件栈与模型可能**二选一**（视目标板卡与 `machine` 默认外设）。  
- **时钟**：USB FS **48MHz** 与 **RCC CFGR/CFGR2/ USBPRE** 见 [03-RCC-寄存器位域详述.md](./03-RCC-寄存器位域详述.md) 与 [`CH32V307-USB-Regs.md`](../CH32V30X/CH32V307-USB-Regs.md)。
