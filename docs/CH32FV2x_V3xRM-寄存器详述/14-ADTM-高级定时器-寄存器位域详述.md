# 高级定时器（ADTM：TIM1 / TIM8 / TIM9 / TIM10）寄存器位域详述

**来源**：《CH32F/V20x_V30x_V31x 系列应用手册》V2.4（[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)），**第 14 章「高级定时器（ADTM）」**（PDF **p183–212**）。  
**按页导出**：[`_layout_extract/ch13-14-tkey-adtm_p180-214.txt`](./_layout_extract/ch13-14-tkey-adtm_p180-214.txt)（表 14-3～14-6）。  
**与通用定时器差异**：本章在 GPTM（第 15 章）基础上增加 **`RPTCR`（重复计数）** 与 **`BDTR`（刹车/死区）** 两个寄存器，以及 **互补输出 `CHxN` / 主输出 `MOE`** 等功能位。详细行为见 PDF 章节对应小节。

> **TIM9/TIM10** 是 WCH 扩展的**高级定时器**（在 STM32 上对应的 TIM9/10 仅是简化定时器，不要混）。

---

## 1. 基址与主要特征

| 定时器 | 基址 | 通道数 | RPTCR | BDTR | 互补输出 |
|--------|------|--------|-------|------|-----------|
| **TIM1**  | `0x40012C00` | 4（全） | 有 | 有 | CH1N/CH2N/CH3N |
| **TIM8**  | `0x40013400` | 4（全） | 有 | 有 | CH1N/CH2N/CH3N |
| **TIM9**  | `0x40014C00` | 4（全） | 有 | 有 | CH1N/CH2N/CH3N |
| **TIM10** | `0x40015000` | 4（全） | 有 | 有 | CH1N/CH2N/CH3N |

主要特征：
- **16 位增/减 / 中央对齐**计数器，**带缓冲** `ATRLR` 自动重载；
- 多达 **4 个独立通道**：**输入捕获、输出比较、PWM（边沿/中央对齐）、单脉冲**；
- **互补输出**含**可编程死区** + **刹车输入**（`BKIN`）+ **刹车中断**；
- **重复计数器**：每 `RPTCR+1` 次计数器溢出才生一次 **更新事件（UEV）**；
- **主/从模式同步**：与其它定时器或 ADC 的 **TRGO** 双向触发；
- **编码器接口**（A/B 增量编码器 + 索引）；
- **DMA 请求**（每通道 + 更新 + 触发 + `COM`）。

## 3. 与 GPTM 不同的核心位域

### 3.1 `CTLR1`（`0x00`）

位域与 GPTM（[15-16-TIM](./15-16-TIM-通用与基本定时器-寄存器概览.md)）完全一致：`[9:8] CKD` / `7 ARPE` / `[6:5] CMS` / `4 DIR` / `3 OPM` / `2 URS` / `1 UDIS` / `0 CEN`。

### 3.2 `CTLR2`（`0x04`）— **新增 `CCPC/CCUS/COM/OIS*`**

| 位 | 名称 | 描述 |
|----|------|------|
| 14 | `OIS4` | `MOE=0` 时（死区后）OC4 空闲电平 |
| 13 | `OIS3N` | OC3N 空闲电平 |
| 12 | `OIS3` | OC3 空闲电平 |
| 11 | `OIS2N` | OC2N 空闲电平 |
| 10 | `OIS2` | OC2 空闲电平 |
| 9  | `OIS1N` | OC1N 空闲电平 |
| 8  | `OIS1` | OC1 空闲电平 |
| 7  | `TI1S` | TI1 选择：`0`=CH1 直连；`1`=CH1⊕CH2⊕CH3 |
| `[6:4]` | `MMS[2:0]` | 主模式 TRGO：`000` 复位 / `001` 使能 / `010` 更新 / `011` 比较脉冲 / `100..111` OCxREF |
| 3  | `CCDS` | 捕获比较 DMA 请求时机：`0`=CCxG 时 / `1`=更新事件时 |
| 2  | `CCUS` | 若 `CCPC=1`：`0`=仅 `COM` 更新 / `1`=`COM` 或 `TRGI` 上升沿更新（仅对互补通道） |
| 0  | `CCPC` | **预装载控制**：`1`=`CCxE/CCxNE/OCxM` 预装，仅 `COM` 事件更新 |

### 3.3 `DMAINTENR`（`0x0C`）

新增 **`TDE(14)` 触发 DMA**、**`COMDE(13)`** COM DMA、**`BIE(7)` 刹车中断**、**`TIE(6)` 触发中断**、**`COMIE(5)` COM 中断**。

### 3.4 `INTFR`（`0x10`）

新增 **`CCxOF(12..9)` 重复捕获标志**、**`BIF(7)` 刹车中断标志**、**`TIF(6)`**、**`COMIF(5)`**。

### 3.5 `SWEVGR`（`0x14`）

新增 **`BG(7)` 刹车软件事件**、**`TG(6)` 触发**、**`COMG(5)` COM**、各通道 `CCxG(1..4)`、更新 `UG(0)`。

### 3.6 `CHCTLR1 / 2`（`0x18 / 0x1C`）

输入捕获模式：`CCxS[1:0]` 通道源（`01` TIx、`10` TI(x+1)、`11` TRC）；`ICxPSC[1:0]` 分频；`ICxF[3:0]` 滤波。  
输出比较模式：`OCxM[2:0]`（`000`=冻结、`001`=主动、`010`=非主动、`011`=翻转、`110`=PWM1、`111`=PWM2）；`OCxPE/OCxCE/OCxFE`；`CC1S=00` 为输出。

### 3.7 `CCER`（`0x20`）

**`CCxE(0/4/8/12)` 输出使能**、**`CCxP(1/5/9/13)` 极性**、**`CCxNE(2/6/10)` 互补输出使能**、**`CCxNP(3/7/11)` 互补极性**（CC4 无互补）。

### 3.8 `RPTCR`（`0x30`）— 重复计数器

| 位 | 名称 | 描述 |
|----|------|------|
| `[15:8]` | Reserved | — |
| `[7:0]` | `REP[7:0]` | 重复计数值；**边沿对齐**下每 `REP+1` 次溢出一次 UEV；**中央对齐**下每 `REP+1` 次溢出/下溢一次 UEV |

### 3.9 `BDTR`（`0x44`）— 刹车与死区

| 位 | 名称 | 描述 |
|----|------|------|
| 15 | `MOE` | 主输出使能；刹车时硬件清 0；需软件或 `AOE` 恢复 |
| 14 | `AOE` | 自动输出使能（下一 UEV 时硬件 `MOE=1`） |
| 13 | `BKP` | 刹车输入极性：`0`=低有效 / `1`=高有效 |
| 12 | `BKE` | 刹车使能 |
| 11 | `OSSR` | 运行时空闲状态：`1`=OCxN 强制空闲（非活动）；`0`=由 `CCxNE` 决定 |
| 10 | `OSSI` | 空闲时空闲状态 |
| `[9:8]` | `LOCK[1:0]` | 写保护级别：`00` 无、`01` LOCK1、`10` LOCK2、`11` LOCK3 |
| `[7:0]` | `DTG[7:0]` | **死区时间**，分段编码：`0xxxxxxx`=DTG×Tdts；`10xxxxxx`=(64+DTG[5:0])×2×Tdts；`110xxxxx`=(32+DTG[4:0])×8×Tdts；`111xxxxx`=(32+DTG[4:0])×16×Tdts |

### 3.10 `DMACFGR` / `DMAADR`（`0x48/0x4C`）— 连续 DMA

`DMACFGR.DBL[4:0]` DMA 突发长度（1..18 项），`DBA[4:0]` 基地址寄存器号；`DMAADR` 通过**一个地址**连续访问多个 TIM 寄存器（用于 DMA 一次刷新多寄存器）。

### 3.11 `AUX`（`0x50`）— **WCH 扩展**

**双边沿捕获** 等增强；具体位见 14.3.11 / 14.4 末。

## 4. 通道 PWM 输出编程例

```
1. RCC: APB2PCENR.TIM1EN=1
2. 配置 GPIO (CH1/CH1N/BKIN) 为复用推挽输出/浮空输入
3. PSC, ATRLR: 设定周期；ARPE=1 预装载
4. CH1CVR: 占空比；OCxM=110 (PWM1)；OCxPE=1
5. CCER: CC1E=1, CC1NE=1，设置 CC1P/CC1NP 极性
6. BDTR: DTG 死区；MOE=1（必须！否则输出保持空闲）
7. CTLR1.CEN=1 启动
```

## 5. 中断源 / NVIC 入口

- `TIM1/8/9/10_BRK_IRQn`：刹车中断 `BIF`
- `TIM1/8/9/10_UP_IRQn`：更新中断 `UIF`
- `TIM1/8/9/10_TRG_COM_IRQn`：触发 `TIF` / COM `COMIF`
- `TIM1/8/9/10_CC_IRQn`：通道捕获/比较 `CCxIF`

NVIC 向量号见 [09-EXTI-PFIC-STK-寄存器位域详述.md](./09-EXTI-PFIC-STK-寄存器位域详述.md) 与手册表 9-1/9-2。
