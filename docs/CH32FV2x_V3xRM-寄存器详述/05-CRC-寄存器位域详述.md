# CRC（循环冗余校验）寄存器位域详述

**来源**：《CH32F/V20x_V30x_V31x 系列应用手册》V2.4（[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)），**第 5 章「循环冗余校验（CRC）」**（PDF **p60–61**）。  
**适用**：CH32F20x / V20x / V30x / V31x **全系列**。

---

## 1. 主要特征

- **CRC32 多项式 `0x4C11DB7`**（固定）：x³²+x²⁶+x²³+x²²+x¹⁶+x¹²+x¹¹+x¹⁰+x⁸+x⁷+x⁵+x⁴+x²+x+1；
- 同一 32 位寄存器 `CRC_DATAR` **写入新数据** / **读取累计 CRC**；
- **单次转换** = 4 个 HCLK 周期；**计算粒度**：整 32 位（**不**逐字节）；
- `CRC_IDATAR` 另提供 **8 位独立缓冲**，**不受 `RST` 影响**。

---

## 2. 表 5-1 寄存器（基址 `0x40023000`）

| 名称 | 地址 | 偏移 | 描述 | 复位值 |
|------|------|------|------|--------|
| `R32_CRC_DATAR` | `0x40023000` | `+0x00` | 数据 | `0xFFFFFFFF` |
| `R8_CRC_IDATAR` | `0x40023004` | `+0x04` | 独立缓冲 | `0x00` |
| `R32_CRC_CTLR` | `0x40023008` | `+0x08` | 控制 | `0x00000000` |

> 使用前需 `RCC_AHBPCENR.CRCEN(bit6)=1`。

---

## 3. 位域

### 3.1 `R32_CRC_DATAR`（偏移 `0x00`）

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[31:0]` | **`DR[31:0]`** | RW | **写** = 输入原始数据；**读** = 当前累计 CRC | `0xFFFFFFFF` |

### 3.2 `R8_CRC_IDATAR`（偏移 `0x04`）

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[7:0]` | **`IDR[7:0]`** | RW | 通用 8 位缓存，**不受 `CTLR.RST` 影响** | 0 |

### 3.3 `R32_CRC_CTLR`（偏移 `0x08`）

| 位 | 名称 | 访问 | 描述 | 复位 |
|----|------|------|------|------|
| `[31:1]` | Reserved | RO | — | 0 |
| 0 | **`RST`** | WO | 写 1 复位 CRC 计算单元（`DATAR` → `0xFFFFFFFF`），硬件自动清零 | 0 |

---

## 4. 典型时序

```c
RCC->AHBPCENR |= RCC_CRCEN;
CRC->CTLR = 1;                  // RST=1, 硬件自清
for (uint32_t i = 0; i < n; i++)
    CRC->DATAR = words[i];      // 写入 32 位原始数据
uint32_t crc = CRC->DATAR;      // 读回累计 CRC
```
