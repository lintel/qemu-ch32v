# DAC 寄存器位域详述

**来源**：《CH32FV2x_V3xRM》**第 17 章**；表 **17-1**（触发源）、**17-2** 与 **17.4.x**。  
**原文**：[`../CH32FV2x_V3xRM.PDF`](../CH32FV2x_V3xRM.PDF)（V2.4 约 **PDF 第 246–258 页**）。  
**头文件**：`DAC_TypeDef` 与**表 17-2 顺序/偏移**一致，基址 **`0x40007400`**（APB1）。

## 1. 表 17-2 全表（R32_ 与地址）

| 地址 | 寄存器 | 说明 |
|------|--------|------|
| `0x40007400` | `R32_DAC_CTLR` | 两通道使能/缓冲/触发/TSEL/波形成形/DMA 等 |
| `0x40007404` | `R32_DAC_SWTR` | 软件触发位 |
| `0x40007408` | `R32_DAC_R12BDHR1` | 通道 1 右 12 位 DHR |
| `0x4000740C` | `R32_DAC_L12BDHR1` | 通道 1 左 12 位 DHR |
| `0x40007410` | `R32_DAC_R8BDHR1` | 通道 1 右 8 位 DHR |
| `0x40007414` | `R32_DAC_R12BDHR2` | 通道 2 右 12 位 DHR |
| `0x40007418` | `R32_DAC_L12BDHR2` | 通道 2 左 12 位 DHR |
| `0x4000741C` | `R32_DAC_R8BDHR2` | 通道 2 右 8 位 DHR |
| `0x40007420` | `R32_DAC_RD12BDHR` | 双通道 12 位打包写 |
| `0x40007424` | `R32_DAC_LD12BDHR` | 双通道左对齐打包写 |
| `0x40007428` | `R32_DAC_RD8BDHR` | 双通道 8 位 |

## 2. `DAC_CTLR`（`0x00`）— 两通道对称

**每通道半字 16 位 域**（`CH1` 在 **[15:0]**，`CH2` 在 **[31:16]** 镜像结构）含：

- **ENx**、**BOFFx**（输出缓冲关断）、**TENx**（外部/定时器/软件触发）、**TSELx[2:0]**（`TIM6/8/7/5/2/4/EXTI9/软件` 等，表 **17-1** 与 17.4.1 一致）  
- **WAVEx[1:0]**：禁止 / **噪声** / **三角**波  
- **MAMPx[3:0]**：噪声屏蔽位宽或**三角波幅**分级  
- **DMAENx**（DMA 双通道独立）

**触发与波形发生器** 的**同步、幅值、LFSR 预装** 见 **17.2～17.3.11** 时序注。

## 3. `DAC_SWTR`（`0x04`）

- 软件置位以产生**软件触发**；与 **TEN=1 且 TSEL=软件** 配合（见 17.4.2 类小节原文）。

## 4. 对齐与双通道写

- **R12 / L12 / R8** 为单通道 DHR 对齐；**RD12/LD12/RD8 双字** 一次写两通道路径见 **17.1** 与寄存器小标题。
